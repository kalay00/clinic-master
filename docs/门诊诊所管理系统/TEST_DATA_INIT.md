## 二、使用方法

### 前置条件

1. **确保数据库服务运行**
   ```bash
   cd /home/laknl/his
   podman ps --filter "name=his_postgres"
   # 或
   docker ps --filter "name=his_postgres"
   ```

2. **安装Python依赖**
   ```bash
   cd /home/laknl/his/backend
   pip install -r requirements.txt
   # 或安装最小依赖
   pip install pydantic-settings sqlalchemy psycopg2-binary passlib[bcrypt] python-jose[cryptography] cryptography
   ```

3. **确保数据库表已创建**
   ```bash
   cd /home/laknl/his/backend
   python3 -m app.core.init_db
   # 或者使用Alembic迁移
   alembic upgrade head
   ```

### 方式1: 使用初始化脚本（推荐）

```bash
cd /home/laknl/his/backend
bash scripts/init_test_data.sh
```

### 方式2: 使用Python直接运行

```bash
cd /home/laknl/his/backend
python3 -c "from app.core.init_test_data import init_test_data; init_test_data()"
```

### 方式3: 使用init_db.py（包含表创建和数据初始化）

```bash
cd /home/laknl/his/backend
python3 -m app.core.init_db
```

### 方式4: 在Python交互式环境中运行

```bash
cd /home/laknl/his/backend
python3
>>> from app.core.init_test_data import init_test_data
>>> init_test_data()
```

## 四、数据初始化流程

1. **创建租户**
   - 创建2个测试租户

2. **创建权限**
   - 为每个租户创建16个权限

3. **创建角色**
   - 为每个租户创建5个角色（管理员、医生、护士、药师、收费员）
   - 为每个角色分配相应权限

4. **创建用户**
   - 为每个租户创建6个用户
   - 所有用户密码设置为111111
   - 为用户分配相应角色

5. **创建患者**
   - 为每个租户创建5个患者
   - 患者敏感数据加密存储

6. **创建药品和库存**
   - 为每个租户创建8个药品
   - 为每个药品创建库存记录

## 五、注意事项

1. **密码安全**
   - 所有测试用户密码均为 `111111`
   - 生产环境请务必修改密码

2. **数据加密**
   - 患者姓名、身份证、手机号已加密存储
   - 使用AES-256-GCM加密算法

3. **多租户隔离**
   - 每个租户的数据完全隔离
   - 用户登录时需要指定租户

4. **重复执行**
   - 如果重复执行初始化脚本，可能会因为唯一约束冲突而失败
   - 建议先清空数据库或使用数据库迁移工具

5. **外键约束**
   - 部分功能（如排班、挂号）需要医生和科室数据
   - 当前初始化脚本未包含这些数据，需要后续补充
