## 使用说明

1. **访问页面**: 系统管理 > 科室管理
2. **查看列表**: 页面加载时自动显示科室列表
3. **搜索科室**: 在搜索框输入关键词，点击搜索或按回车
4. **新增科室**: 点击"新增科室"按钮，填写表单后提交
5. **编辑科室**: 点击表格中的"编辑"按钮，修改后提交
6. **删除科室**: 点击表格中的"删除"按钮，确认后删除

## 注意事项

1. **科室编码**: 创建后不可修改，建议使用英文大写字母
2. **编码唯一性**: 同一租户内科室编码必须唯一
3. **软删除**: 删除操作是软删除，不会真正删除数据
4. **多租户**: 所有操作都自动关联当前租户
