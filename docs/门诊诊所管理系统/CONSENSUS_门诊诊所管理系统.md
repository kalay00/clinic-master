# CONSENSUS_门诊诊所管理系统

## 一、项目概述

### 1.1 项目名称
门诊诊所管理系统（HIS - Hospital Information System）

### 1.2 项目定位
面向中小型门诊、诊所的云端SaaS管理系统，支持多租户、多机构部署，提供完整的门诊业务流程管理。

### 1.3 目标用户
- 中小型门诊（日接诊量：50-500人次）
- 各类专科诊所（口腔、中医、专科等）
- **中医特色门诊**（支持完整的中医诊疗流程）
- **中西医结合门诊**（同时支持中医和西医诊疗方式）
- 社区医疗服务站
- 支持多机构、多租户模式

## 二、明确的需求描述

### 2.1 核心业务需求

#### 2.1.1 患者管理模块
- **患者档案管理**: 患者基本信息、就诊历史、过敏史、慢性病史等
- **患者查询**: 支持多种查询方式（姓名、身份证、电话、病历号等）
- **患者信息维护**: 新增、编辑、删除（软删除）、合并患者信息
- **数据统计**: 患者就诊统计、患者分布分析

#### 2.1.2 挂号预约模块
- **预约挂号**: 支持现场挂号、预约挂号、微信预约
- **排班管理**: 医生排班、科室排班、时段管理
- **号源管理**: 号源分配、退号、改号
- **挂号统计**: 挂号量统计、预约率分析

#### 2.1.3 诊疗记录模块
- **病历书写**: 电子病历、病历模板、病历归档
- **诊断管理**: 
  - 西医诊断：诊断录入、ICD编码、诊断历史
  - **中医诊断：证型录入、病机分析、中医诊断历史**
  - **中西医结合诊断：支持中西医联合诊断**
- **处方管理**: 
  - 西医处方：电子处方、处方审核、处方打印
  - **中药处方：中药处方、方剂管理、中药配伍审核**
  - **中西药联合处方：支持中西药联合开具**
- **检查申请**: 检查申请单、检查结果录入（不含LIS对接）
- **中医特色功能**:
  - **四诊记录**：望、闻、问、切四诊信息记录
  - **中医体质辨识**：九种体质辨识和记录
  - **治疗方法记录**：针灸、推拿、拔罐、艾灸等治疗方法
  - **中药方剂管理**：经方、验方、协定方管理

#### 2.1.4 收费结算模块
- **费用计算**: 自动计算费用、医保报销计算
- **收费结算**: 多种支付方式（现金、微信、支付宝、银行卡、医保）
- **退费管理**: 退费申请、退费审批、退费记录
- **收费统计**: 收费明细、收费汇总、欠费管理

#### 2.1.5 药房管理模块
- **药品管理**: 
  - 西药管理：药品信息、药品分类、药品规格
  - **中药管理：中药材、中药饮片、中成药管理**
  - **中药分类**：按功效分类（解表、清热、补益等）
  - **中药规格**：支持单位换算（克、两、钱等）
- **库存管理**: 
  - 西药库存：入库、出库、盘点、库存预警
  - **中药库存：中药材库存、饮片库存、中成药库存**
  - **中药保质期管理**：中药材保质期、饮片保质期
- **进销存**: 采购管理、销售统计、库存报表
- **处方发药**: 
  - 西药处方发药：处方审核、发药确认、发药记录
  - **中药处方发药：中药处方审核、中药饮片调配、发药记录**
  - **中药煎药管理**：代煎服务、煎药记录

#### 2.1.6 报表统计模块
- **经营报表**: 收入统计、支出统计、利润分析
- **业务报表**: 就诊量统计、医生工作量、科室统计
- **患者报表**: 患者统计、复诊率、患者分析
- **药品报表**: 药品销售、库存分析、采购建议

#### 2.1.7 系统管理模块
- **用户管理**: 用户创建、角色分配、权限配置
- **机构管理**: 机构信息、多租户隔离、数据隔离
- **基础数据**: 科室管理、医生管理、药品字典、收费项目
- **系统配置**: 系统参数、打印模板、通知模板

### 2.2 特殊功能需求

#### 2.2.1 医保对接
- **医保接口**: 对接医保系统，实现医保结算
- **医保查询**: 医保账户查询、医保政策查询
- **报销计算**: 自动计算医保报销金额

#### 2.2.2 打印功能
- **处方打印**: 支持多种处方格式
- **收费单打印**: 收费明细单、发票
- **报表打印**: 各类统计报表打印
- **打印模板**: 可配置的打印模板

#### 2.2.3 扫码功能
- **药品扫码**: 药品入库、出库扫码
- **患者扫码**: 患者身份识别、快速挂号
- **支付扫码**: 生成支付二维码

#### 2.2.4 通知功能
- **短信通知**: 预约提醒、检查结果通知、缴费提醒
- **微信通知**: 微信公众号消息推送、微信小程序通知
- **通知模板**: 可配置的通知模板

#### 2.2.5 支付对接
- **支付方式**: 现金、微信支付、支付宝、银行卡、医保支付
- **支付接口**: 对接第三方支付平台
- **支付记录**: 完整的支付流水记录

### 2.3 非功能性需求

#### 2.3.1 性能要求
- **响应时间**: 页面响应时间 < 2秒
- **并发支持**: 支持100+并发用户
- **数据处理**: 支持日接诊量500+人次的数据处理

#### 2.3.2 安全要求
- **数据加密**: 
  - 传输加密（HTTPS/TLS）
  - 敏感数据存储加密（AES-256）
  - 数据库加密字段加密
- **访问控制**: 
  - 细粒度权限控制（角色+功能+数据权限）
  - 多租户数据隔离
  - 操作日志审计
- **合规要求**: 
  - 符合《网络安全法》
  - 符合《个人信息保护法》
  - 符合医疗数据保护相关法规

#### 2.3.3 可用性要求
- **界面要求**: 简洁易用，适合年龄较大的医生使用
- **响应式设计**: 支持PC、平板、移动端全平台
- **浏览器兼容**: 支持主流浏览器（Chrome、Firefox、Safari、Edge）

#### 2.3.4 扩展性要求
- **微服务架构**: 支持服务独立部署和扩展
- **多租户支持**: 支持多机构、多租户模式
- **接口开放**: 预留第三方系统对接接口

## 三、技术实现方案

### 3.1 技术栈选择

#### 3.1.1 后端技术栈
- **开发语言**: Python 3.9+
- **Web框架**: FastAPI（推荐，高性能，自动API文档）或 Flask
- **ORM框架**: SQLAlchemy
- **异步框架**: 使用 FastAPI 的异步特性或 asyncio
- **任务队列**: Celery + Redis（异步任务处理）
- **API文档**: FastAPI 自动生成（Swagger/OpenAPI）

#### 3.1.2 前端技术栈
- **基础**: 原生 HTML5 + CSS3 + JavaScript (ES6+)
- **UI框架**: 可选轻量级框架（如 Bootstrap 或 Tailwind CSS）
- **响应式**: 使用 CSS Grid/Flexbox 实现响应式布局
- **AJAX**: 使用 Fetch API 或 Axios 进行API调用
- **打包工具**: 可选 Webpack 或 Vite（用于生产环境优化）

#### 3.1.3 数据库
- **主数据库**: PostgreSQL 12+
  - 存储业务数据
  - 支持JSON字段存储灵活数据
  - 支持事务和复杂查询
- **缓存数据库**: Redis 6+
  - 会话存储（Session）
  - 缓存热点数据
  - 任务队列（Celery Broker）
  - 分布式锁

#### 3.1.4 微服务架构
- **服务拆分原则**:
  - 用户服务（认证、授权、用户管理）
  - 患者服务（患者档案管理）
  - 挂号服务（挂号、预约、排班）
  - 诊疗服务（病历、诊断、处方）
  - 收费服务（收费、结算、支付）
  - 药房服务（药品、库存、进销存）
  - 报表服务（统计、报表生成）
  - 通知服务（短信、微信通知）
  - 对接服务（医保、支付、微信）
- **服务通信**: RESTful API + 消息队列（RabbitMQ或Redis）
- **服务注册**: Consul 或 etcd
- **API网关**: Kong 或 Nginx + Lua

#### 3.1.5 部署架构
- **容器化**: Docker + Docker Compose（开发环境）
- **容器编排**: Kubernetes（生产环境）
- **负载均衡**: Nginx
- **反向代理**: Nginx
- **文件存储**: 对象存储（MinIO 或 阿里云OSS）
- **监控**: Prometheus + Grafana
- **日志**: ELK Stack（Elasticsearch + Logstash + Kibana）

### 3.2 技术约束

#### 3.2.1 开发约束
- **代码规范**: 遵循 PEP 8（Python）、ESLint（JavaScript）
- **API设计**: RESTful API 设计规范
- **数据库设计**: 遵循数据库设计范式，支持多租户
- **版本控制**: Git，分支管理策略（Git Flow）

#### 3.2.2 安全约束
- **API安全**: JWT Token 认证，Token 过期机制
- **数据加密**: 敏感字段加密存储（患者姓名、身份证、电话等）
- **SQL注入防护**: 使用ORM参数化查询
- **XSS防护**: 前端输入验证和转义
- **CSRF防护**: CSRF Token 验证

#### 3.2.3 性能约束
- **数据库优化**: 索引优化、查询优化、连接池
- **缓存策略**: Redis缓存热点数据，减少数据库压力
- **异步处理**: 耗时操作异步处理（如通知发送、报表生成）

### 3.3 集成方案

#### 3.3.1 医保系统对接
- **对接方式**: HTTP/HTTPS API 对接
- **数据格式**: JSON/XML
- **安全认证**: 数字证书认证
- **接口类型**: 实时接口（结算、查询）

#### 3.3.2 微信公众号/小程序对接
- **对接方式**: 微信开放平台API
- **功能**: 
  - 微信公众号消息推送
  - 微信小程序登录
  - 微信支付
  - 微信通知

#### 3.3.3 支付系统对接
- **微信支付**: 微信支付API
- **支付宝**: 支付宝开放平台API
- **银行卡**: 银联支付API
- **支付回调**: 异步回调处理

#### 3.3.4 短信服务对接
- **对接方式**: 第三方短信服务商API（如阿里云短信、腾讯云短信）
- **功能**: 预约提醒、结果通知、缴费提醒
