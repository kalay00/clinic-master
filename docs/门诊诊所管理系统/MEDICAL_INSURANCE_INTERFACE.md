# 医保接口规范文档

## 一、概述

本文档描述门诊诊所管理系统与医保系统的接口规范和对接方案。

### 1.1 医保系统对接方式

根据实际医保系统类型，系统支持以下对接方式：
- **标准医保接口**: 符合国家医保局标准的接口规范
- **地方医保接口**: 符合地方医保局接口规范
- **第三方医保平台**: 通过第三方平台对接医保系统

### 1.2 当前实现状态

- ✅ **接口框架已实现**: 医保验证和医保支付接口已实现框架
- ⚠️ **待对接实际系统**: 需要根据实际医保系统调整接口参数和响应格式
- ✅ **配置化支持**: 支持通过第三方服务配置管理医保接口参数

## 二、接口规范

### 2.1 医保验证接口

#### 接口路径
`POST /api/v1/integrations/medical-insurance/verify`

#### 功能描述
验证患者医保信息，查询医保账户余额、报销比例等信息。

#### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| patient_id | string | 是 | 患者ID |
| id_card | string | 是 | 身份证号 |

#### 请求示例
```json
{
    "patient_id": "uuid",
    "id_card": "110101199001011234"
}
```

#### 响应格式

**成功响应**:
```json
{
    "code": 200,
    "message": "验证成功",
    "data": {
        "verified": true,
        "insurance_type": "basic",
        "insurance_no": "YB1234567890",
        "balance": 1000.0,
        "coverage_rate": 0.8,
        "personal_account": 500.0,
        "social_account": 500.0,
        "valid_until": "2025-12-31"
    },
    "timestamp": "2024-12-19T10:00:00"
}
```

**失败响应**:
```json
{
    "code": 400,
    "message": "医保验证失败",
    "data": {
        "details": {
            "error_code": "INVALID_ID_CARD",
            "error_message": "身份证号格式错误"
        }
    },
    "timestamp": "2024-12-19T10:00:00"
}
```

#### 响应字段说明

| 字段名 | 类型 | 说明 |
|--------|------|------|
| verified | boolean | 是否验证成功 |
| insurance_type | string | 医保类型：basic(基本医保)/employee(职工医保)/resident(居民医保) |
| insurance_no | string | 医保卡号 |
| balance | float | 医保账户余额（元） |
| coverage_rate | float | 报销比例（0-1之间的小数） |
| personal_account | float | 个人账户余额（元） |
| social_account | float | 统筹账户余额（元） |
| valid_until | string | 医保有效期至（YYYY-MM-DD） |

#### 医保类型说明

- **basic**: 基本医疗保险
- **employee**: 职工医保（城镇职工基本医疗保险）
- **resident**: 居民医保（城乡居民基本医疗保险）

### 2.2 医保支付接口

#### 接口路径
`POST /api/v1/integrations/medical-insurance/pay`

#### 功能描述
使用医保账户支付账单，扣除医保账户余额。

#### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| bill_id | string | 是 | 账单ID |
| amount | float | 是 | 支付金额（元） |

#### 请求示例
```json
{
    "bill_id": "uuid",
    "amount": 100.0
}
```

#### 响应格式

**成功响应**:
```json
{
    "code": 200,
    "message": "支付成功",
    "data": {
        "success": true,
        "transaction_id": "INS2024121900001",
        "paid_amount": 100.0,
        "personal_paid": 50.0,
        "social_paid": 50.0,
        "remaining_balance": 900.0,
        "payment_time": "2024-12-19T10:00:00"
    },
    "timestamp": "2024-12-19T10:00:00"
}
```

**失败响应**:
```json
{
    "code": 400,
    "message": "医保支付失败",
    "data": {
        "details": {
            "error_code": "INSUFFICIENT_BALANCE",
            "error_message": "医保账户余额不足"
        }
    },
    "timestamp": "2024-12-19T10:00:00"
}
```

#### 响应字段说明

| 字段名 | 类型 | 说明 |
|--------|------|------|
| success | boolean | 是否支付成功 |
| transaction_id | string | 医保交易流水号 |
| paid_amount | float | 实际支付金额（元） |
| personal_paid | float | 个人账户支付金额（元） |
| social_paid | float | 统筹账户支付金额（元） |
| remaining_balance | float | 剩余账户余额（元） |
| payment_time | string | 支付时间（ISO 8601格式） |

### 3.3 常见医保系统对接方案

#### 方案1: 国家医保局标准接口
- **接口规范**: 符合国家医保局接口规范
- **对接方式**: 直接对接医保局接口
- **证书要求**: 需要申请医保局颁发的数字证书

#### 方案2: 地方医保局接口
- **接口规范**: 符合地方医保局接口规范
- **对接方式**: 对接地方医保局接口
- **证书要求**: 需要申请地方医保局颁发的数字证书

#### 方案3: 第三方医保平台
- **接口规范**: 第三方平台提供的接口规范
- **对接方式**: 通过第三方平台对接医保系统
- **证书要求**: 根据第三方平台要求

### 3.4 错误处理

#### 常见错误码

| 错误码 | 说明 | 处理建议 |
|--------|------|---------|
| INVALID_ID_CARD | 身份证号格式错误 | 检查身份证号格式 |
| ID_CARD_NOT_FOUND | 身份证号未找到 | 确认患者是否已参保 |
| INSUFFICIENT_BALANCE | 账户余额不足 | 提示患者账户余额不足 |
| INSURANCE_EXPIRED | 医保已过期 | 提示患者医保已过期 |
| SYSTEM_ERROR | 医保系统错误 | 联系医保局或稍后重试 |

#### 错误处理策略
- **网络错误**: 自动重试3次，间隔1秒
- **业务错误**: 返回具体错误信息给用户
- **系统错误**: 记录日志，联系技术支持
