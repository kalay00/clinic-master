## 七、数据一致性验证测试

### 7.1 库存数量验证
**测试步骤**：
1. 记录初始库存数量（如：100）
2. 创建并入库一个采购单（数量：20）
3. 检查库存是否变为：120（100 + 20）
4. 创建并完成一个盘点单（差异：+5）
5. 检查库存是否变为：125（120 + 5）

**预期结果**：
- ✅ 库存数量计算正确
- ✅ 每次操作后库存正确更新

### 7.2 流水记录验证
**测试步骤**：
1. 执行采购入库操作
2. 在库存流水中查找对应的记录
3. 验证流水记录：
   - 类型：采购入库
   - 数量：与采购数量一致
   - 变动前库存：入库前的库存
   - 变动后库存：入库后的库存
4. 执行盘点完成操作
5. 在库存流水中查找对应的记录
6. 验证流水记录：
   - 类型：盘点调整
   - 数量：与差异数量一致
   - 变动前库存：盘点前的库存
   - 变动后库存：盘点后的库存
   - 变动后库存 = 变动前库存 + 数量

**预期结果**：
- ✅ 每个操作都有对应的流水记录
- ✅ 流水记录数据正确
- ✅ 流水记录连续（前一条的after = 后一条的before）

### 7.3 状态流转验证
**测试步骤**：
1. 创建采购单 → 状态应为"草稿"
2. 审核采购单 → 状态应为"已审核"
3. 入库采购单 → 状态应为"已入库"
4. 创建盘点单 → 状态应为"草稿"
5. 完成盘点 → 状态应为"已完成"

**预期结果**：
- ✅ 状态流转正确
- ✅ 不允许跳过状态（如草稿直接入库）
- ✅ 不允许逆向操作（如已入库不能回到草稿）
