# 平台管理员功能测试报告

## 一、测试概述

### 1.1 测试目标

验证平台管理员功能的完整性和正确性，包括：
- 平台管理员登录
- 租户管理（CRUD操作）
- 前端页面集成
- API接口调用

### 1.2 测试环境

- **后端服务**: FastAPI (http://localhost:8000)
- **前端服务**: 静态文件服务
- **数据库**: PostgreSQL
- **测试账号**: platform_admin / 111111

## 二、后端API测试

### 2.1 平台管理员登录测试

#### 测试用例
```
POST /api/v1/platform/login
{
    "username": "platform_admin",
    "password": "111111"
}
```

#### 预期结果
- HTTP状态码: 200
- 响应code: 200
- 返回access_token和refresh_token
- 返回用户信息（role为platform_admin）

#### 测试步骤
1. 运行测试脚本: `python3 tests/test_platform_admin.py`
2. 或手动调用API进行测试

### 2.2 获取租户列表测试

#### 测试用例
```
GET /api/v1/platform/tenants?skip=0&limit=10
Authorization: Bearer {token}
```

#### 预期结果
- HTTP状态码: 200
- 响应code: 200
- 返回租户列表（items数组）
- 返回分页信息（total, page, page_size）

### 2.3 创建租户测试

#### 测试用例
```
POST /api/v1/platform/tenants
Authorization: Bearer {token}
{
    "name": "测试租户",
    "code": "TESTXXX",
    "type": "clinic",
    "status": "active"
}
```

#### 预期结果
- HTTP状态码: 200
- 响应code: 200
- 返回创建的租户信息
- 数据库中新增租户记录

### 2.4 更新租户测试

#### 测试用例
```
PUT /api/v1/platform/tenants/{id}
Authorization: Bearer {token}
{
    "name": "更新后的名称",
    "status": "active"
}
```

#### 预期结果
- HTTP状态码: 200
- 响应code: 200
- 租户信息更新成功
- 数据库中记录更新

### 2.5 删除租户测试

#### 测试用例
```
DELETE /api/v1/platform/tenants/{id}
Authorization: Bearer {token}
```

#### 预期结果
- HTTP状态码: 200
- 响应code: 200
- 租户软删除成功（deleted_at字段更新）
- 租户仍存在于数据库，但状态为已删除
