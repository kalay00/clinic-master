# TASK_03_患者服务

## 任务概览

患者服务模块包含患者档案管理、就诊历史查询等功能。

## 任务列表

### TASK_03_01: 患者模型和数据库操作

#### 输入契约
- **前置依赖**: TASK_01_02（数据库初始化）, TASK_02_01（用户服务）
- **输入数据**: 
  - 数据库设计文档（patients表）
- **环境依赖**: 
  - PostgreSQL
  - SQLAlchemy

#### 输出契约
- **输出数据**: 
  - 患者数据模型
- **交付物**:
  - `backend/services/patient_service/models.py`
  - 患者CRUD操作
  - 患者查询操作
  - 数据加密/解密处理
- **验收标准**:
  - 患者模型定义正确
  - CRUD操作功能完整
  - 敏感数据加密存储
  - 多租户隔离生效
  - 单元测试通过（覆盖率>80%）

#### 实现约束
- **技术栈**: 
  - SQLAlchemy ORM
  - PostgreSQL
  - 数据加密组件（TASK_01_05）
- **接口规范**: Repository模式
- **质量要求**: 
  - 敏感字段加密（姓名、身份证、电话）
  - 哈希字段用于查询
  - 代码符合PEP 8
  - 有完整的类型注解

#### 依赖关系
- **前置任务**: TASK_01_02, TASK_02_01, TASK_01_05
- **后置任务**: TASK_03_02, TASK_03_03
- **并行任务**: 无

### TASK_03_02: 患者管理API

#### 输入契约
- **前置依赖**: TASK_03_01, TASK_01_04（API网关）
- **输入数据**: 
  - 患者信息
- **环境依赖**: 
  - FastAPI
  - SQLAlchemy

#### 输出契约
- **输出数据**: 
  - 患者列表
  - 患者详情
- **交付物**:
  - 患者列表接口 (`GET /api/v1/patients`)
  - 患者详情接口 (`GET /api/v1/patients/{id}`)
  - 创建患者接口 (`POST /api/v1/patients`)
  - 更新患者接口 (`PUT /api/v1/patients/{id}`)
  - 删除患者接口 (`DELETE /api/v1/patients/{id}`)
  - 患者搜索接口 (`GET /api/v1/patients/search`)
- **验收标准**:
  - CRUD操作功能完整
  - 搜索功能正常（支持姓名、身份证、电话、病历号）
  - 数据验证通过
  - 权限验证正确
  - 多租户隔离生效
  - 单元测试通过

#### 实现约束
- **技术栈**: 
  - FastAPI
  - SQLAlchemy
  - pydantic (数据验证)
- **接口规范**: 
  - RESTful API
  - 统一响应格式
- **质量要求**: 
  - 数据验证完整
  - 错误处理完善
  - 敏感信息脱敏返回
  - 有单元测试

#### 依赖关系
- **前置任务**: TASK_03_01, TASK_01_04
- **后置任务**: TASK_03_03
- **并行任务**: 无
