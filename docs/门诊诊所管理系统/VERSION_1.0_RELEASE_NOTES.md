# 门诊诊所管理系统 v1.0 版本说明

## 版本信息

- **版本号**: 1.0.0
- **发布日期**: 2024-12-19
- **版本类型**: 正式发布版
- **开发周期**: 2024-12-19

## 版本概述

门诊诊所管理系统 v1.0 是一个功能完整的医院信息管理系统，专为中小型门诊、诊所设计。本版本实现了完整的业务流程管理，包括患者管理、挂号预约、诊疗记录、收费结算、药房管理、报表统计等核心功能，并特别支持中医特色功能和中西医结合诊疗。

## 核心特性

### 1. 多租户架构
- 支持多机构独立运营
- 数据完全隔离，互不干扰
- 平台管理员统一管理所有租户
- 支持用户跨租户访问（多租户用户）
- 支持域名识别和租户代码识别

### 2. 核心业务模块

#### 2.1 患者管理
- 患者档案管理（基本信息、联系方式、病史记录）
- 患者搜索和筛选（姓名、身份证、电话）
- 患者详情查看和编辑
- 就诊历史记录
- 敏感数据加密存储（姓名、身份证、电话）

#### 2.2 挂号预约
- 排班管理（医生排班、号源管理）
- 挂号预约（现场挂号、预约挂号）
- 挂号查询和取消
- 号源实时统计

#### 2.3 诊疗管理
- 病历管理（创建、查看、编辑、打印）
- 处方管理（西药处方、中药处方、中成药处方）
- 支持中西医结合诊疗
- 中医四诊记录（望、闻、问、切）
- 诊断记录和医嘱管理
- 处方详情查看和打印

#### 2.4 收费结算
- 费用自动计算（挂号费、诊疗费、药品费）
- 账单管理（创建、查看、支付、退费）
- 多种支付方式（现金、微信、支付宝、医保）
- 退费管理（部分退费、全额退费）
- 账单明细查看

#### 2.5 药房管理
- 药品管理（西药、中药、中成药）
- 药品分类管理
- 库存管理（入库、出库、盘点）
- 库存预警（低库存提醒）
- 发药管理（处方发药、库存扣减）
- 进销存管理（供应商、采购订单、库存流水、退货管理）

#### 2.6 报表统计
- 收入报表（按日期、按医生、按科室统计）
- 就诊量报表（按日期、按医生统计）
- 药品销售报表（按药品、按日期统计）
- 患者统计报表（新增患者、复诊患者）
- 图表可视化展示（柱状图、折线图、饼图）

### 3. 系统管理

#### 3.1 用户管理
- 用户创建、编辑、删除
- 用户角色分配
- 用户状态管理（激活、禁用）
- 密码管理

#### 3.2 角色权限管理
- 角色创建和管理
- 权限树配置（按资源分组）
- 角色权限分配
- 细粒度权限控制（功能权限 + 数据权限）

#### 3.3 科室管理
- 科室创建、编辑、删除
- 科室信息管理

#### 3.4 医生管理
- 医生信息管理（姓名、科室、职称、挂号费）
- 医生排班管理
- 医生工作量统计

#### 3.5 平台管理
- 平台管理员登录
- 租户管理（创建、编辑、删除、查看）
- 租户状态管理
- 平台统计信息

### 4. 中医特色功能

#### 4.1 中医诊断
- 四诊记录（望、闻、问、切）
- 中医诊断记录
- 证候分析

#### 4.2 中药处方
- 中药处方创建和管理
- 方剂管理（经典方剂、自拟方剂）
- 中药剂量管理
- 煎服方法记录

#### 4.3 中西医结合
- 支持中西医联合诊疗
- 支持中西医联合处方
- 病历类型标识（西医、中医、中西医结合）

### 5. 进销存管理

#### 5.1 供应商管理
- 供应商信息管理
- 供应商联系方式管理
- 供应商状态管理

#### 5.2 采购管理
- 采购订单创建和管理
- 采购入库流程
- 采购订单状态跟踪
- 采购历史记录

#### 5.3 库存管理
- 库存实时查询
- 库存流水记录
- 库存预警设置
- 库存盘点功能

#### 5.4 退货管理
- 退货订单创建
- 退货审批流程
- 退货出库管理

### 6. 其他功能

#### 6.1 打印功能
- 打印模板管理（创建、编辑、删除）
- 支持多种打印模板（病历、处方、账单等）
- 模板变量替换
- 打印预览功能

#### 6.2 操作日志
- 用户操作记录
- 操作日志查询
- 审计日志记录

#### 6.3 通知功能
- 系统通知管理
- 通知发送和接收
- 通知状态跟踪

#### 6.4 文件上传
- 支持图片上传
- 文件存储管理

## 技术架构

### 后端技术栈
- **框架**: FastAPI
- **数据库**: PostgreSQL 15
- **缓存**: Redis 7
- **消息队列**: RabbitMQ 3
- **ORM**: SQLAlchemy
- **认证**: JWT Token
- **加密**: AES-256-GCM

### 前端技术栈
- **框架**: 原生 HTML/CSS/JavaScript
- **UI框架**: Bootstrap 5
- **图标**: Bootstrap Icons
- **图表**: Chart.js
- **架构**: 单页应用（SPA）

### 部署架构
- **容器化**: Docker/Podman
- **数据库**: PostgreSQL（Docker容器）
- **缓存**: Redis（Docker容器）
- **消息队列**: RabbitMQ（Docker容器）
- **部署方式**: 支持云端部署（Docker + Kubernetes）

## 安全特性

### 1. 数据安全
- 敏感数据加密存储（AES-256-GCM）
- 传输加密（HTTPS/TLS）
- 密码加密存储（bcrypt）

### 2. 访问安全
- JWT Token认证
- RBAC权限控制

### 3. 审计安全

## 安装和部署

### 快速开始

1. **克隆项目**
```bash
git clone https://gitee.com/ttlaknl/outpatient-management-system.git
cd outpatient-management-system
```

2. **配置环境变量**
```bash
cp env.example .env
# 编辑 .env 文件，修改数据库密码等配置
```

3. **启动开发环境**
```bash
bash scripts/start-dev.sh
```

4. **初始化数据库和测试数据**
```bash
cd backend
python3 -m app.core.init_test_data
```

5. **启动后端服务**
```bash
cd backend
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

6. **访问系统**
- 前端地址: http://localhost:8000
- API文档: http://localhost:8000/api/docs
- RabbitMQ管理界面: http://localhost:15672
