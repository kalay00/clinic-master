### 2.2 采购单管理测试

#### 测试步骤
1. 访问 `/views/inventory/purchase-orders.html`
2. 点击"新增采购单"按钮
3. 填写采购单信息：
   - 选择供应商
   - 选择采购日期
   - 添加采购明细（至少一条）
     - 选择药品
     - 输入数量
     - 输入单价
     - 可选：批次号、有效期
4. 点击"保存"
5. 验证采购单是否出现在列表中
6. 测试审核功能
   - 点击"审核"按钮
   - 验证状态变为"已审核"
7. 测试入库功能
   - 点击"入库"按钮
   - 验证状态变为"已入库"
   - 验证库存是否更新
   - 验证库存流水是否记录
8. 测试查看详情功能
9. 测试删除功能（草稿状态）

#### 预期结果
- ✅ 采购单创建成功
- ✅ 采购单列表正确显示
- ✅ 审核功能正常
- ✅ 入库功能正常（库存更新、流水记录）
- ✅ 查看详情功能正常
- ✅ 删除功能正常（仅草稿状态）

## 四、API测试

### 4.1 使用Postman或curl测试

#### 供应商API测试
```bash
# 获取供应商列表
curl -X GET "http://localhost:8000/api/v1/inventory/suppliers" \
  -H "Authorization: Bearer YOUR_TOKEN"

# 创建供应商
curl -X POST "http://localhost:8000/api/v1/inventory/suppliers" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "测试供应商",
    "code": "SUP001",
    "contact_name": "张三",
    "contact_phone": "13800138000",
    "status": "active"
  }'
```

#### 采购单API测试
```bash
# 获取采购单列表
curl -X GET "http://localhost:8000/api/v1/inventory/purchase-orders" \
  -H "Authorization: Bearer YOUR_TOKEN"

# 创建采购单
curl -X POST "http://localhost:8000/api/v1/inventory/purchase-orders" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "supplier_id": "SUPPLIER_UUID",
    "order_date": "2024-12-19",
    "items": [
      {
        "drug_id": "DRUG_UUID",
        "quantity": 10,
        "unit_price": 50.0
      }
    ]
  }'
```
