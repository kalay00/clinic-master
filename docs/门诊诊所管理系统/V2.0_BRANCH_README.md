# v2.0 分支开发说明

## 分支信息

- **分支名称**: `v2.0`
- **创建时间**: 2024-12-19

## 分支用途

本分支用于开发门诊诊所管理系统 v2.0 版本，包含以下主要目标：

1. **用户体验提升** - 优化界面交互，提升操作效率
2. **功能增强** - 补充缺失功能，完善业务流程
3. **移动端支持** - 开发移动端应用，支持移动办公
4. **性能优化** - 提升系统响应速度和并发能力
5. **监管合规** - 实现医保、食药监、卫健委监管要求
6. **数据智能化** - 增加数据分析和智能推荐功能

## 开发规范

### 代码提交规范

- 使用语义化提交信息（feat, fix, docs, style, refactor, test, chore）
- 提交信息格式：`<type>: <description>`
- 示例：
  - `feat: 添加移动端登录功能`
  - `fix: 修复患者搜索性能问题`
  - `docs: 更新v2.0开发文档`

### 分支管理

- `master` 分支：稳定版本，仅接受经过测试的代码
- `v2.0` 分支：开发分支，用于v2.0版本功能开发
- 功能分支：从 `v2.0` 分支创建，命名格式：`feature/v2.0-<功能名>`

### 开发流程

1. 从 `v2.0` 分支创建功能分支
2. 在功能分支上开发
3. 完成开发后合并到 `v2.0` 分支
4. 定期将 `master` 分支的更新合并到 `v2.0` 分支
