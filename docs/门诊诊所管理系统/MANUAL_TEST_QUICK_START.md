# 进销存模块人工测试快速开始

## 一、准备工作（5分钟）

### 1.1 启动服务
```bash
# 确保后端服务运行
cd backend
uvicorn app.main:app --reload
```

### 1.2 访问系统
- 打开浏览器：http://localhost:8000
- 登录账号：`admin` / `admin123`

---

## 二、快速测试流程（30分钟）

### 步骤1：供应商管理（5分钟）
1. ✅ 点击"供应商管理"菜单
2. ✅ 点击"新增供应商"
3. ✅ 填写信息并保存
4. ✅ 验证供应商出现在列表中

### 步骤2：采购单管理（10分钟）
1. ✅ 点击"采购单管理"菜单
2. ✅ 点击"新增采购单"
3. ✅ 选择供应商
4. ✅ 添加采购明细（选择药品，输入数量10、单价50）
5. ✅ 保存采购单（状态：草稿）
6. ✅ 点击"审核"按钮（状态：已审核）
7. ✅ 验证库存未变化
8. ✅ 点击"入库"按钮（状态：已入库）
9. ✅ 验证库存增加（+10）

### 步骤3：库存流水验证（5分钟）
1. ✅ 点击"库存流水"菜单
2. ✅ 找到采购入库记录
3. ✅ 验证：
   - 类型：采购入库
   - 数量：+10
   - 变动前后库存正确

### 步骤4：库存盘点（10分钟）
1. ✅ 点击"库存盘点"菜单
2. ✅ 点击"新增盘点单"
3. ✅ 添加盘点明细（选择药品，系统自动获取账面数量）
4. ✅ 输入实际数量（比账面多5）
5. ✅ 保存盘点单（状态：草稿）
6. ✅ 验证库存未变化
7. ✅ 点击"完成盘点"按钮（状态：已完成）
8. ✅ 验证库存调整（+5）

### 步骤5：数据一致性验证（5分钟）
1. ✅ 在库存流水中找到盘点调整记录
2. ✅ 验证：
   - 类型：盘点调整
   - 数量：+5
   - 变动前后库存正确
   - 流水记录连续（前一条的after = 后一条的before）

## 五、常见问题

### Q1: 登录失败？
**A**: 检查后端服务是否启动，用户名密码是否正确。

### Q2: 找不到菜单？
**A**: 检查是否已登录，菜单是否在左侧栏"进销存管理"下。

### Q3: 创建采购单时找不到药品？
**A**: 确保数据库中已有药品数据，或通过API先创建药品。

### Q4: 库存没有变化？
**A**: 检查采购单是否已入库，盘点单是否已完成。

### Q5: 找不到流水记录？
**A**: 确保已执行了采购入库或盘点完成操作。
