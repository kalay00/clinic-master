# 科室管理页面重新开发文档

## 重新开发说明

根据用户要求，重新开发了科室管理功能的前端页面，保持与现有系统管理页面风格统一，CSS样式保持一致。

## 设计原则

1. **风格统一**: 参考用户管理、医生管理等现有系统管理页面的设计风格
2. **Bootstrap 5**: 使用Bootstrap 5组件和样式
3. **响应式设计**: 支持不同屏幕尺寸
4. **用户体验**: 提供清晰的视觉反馈和操作提示

## 页面结构

### 1. 页面头部 (page-header)
- **面包屑导航**: 首页 > 系统管理 > 科室管理
- **标题**: 带图标的"科室管理"标题
- **操作按钮**: "新增科室"按钮（右上角）

### 2. 搜索栏 (card)
- **搜索输入框**: 支持按科室名称或编码搜索
- **搜索按钮**: 带搜索图标
- **重置按钮**: 清除搜索条件
- **回车搜索**: 支持回车键快速搜索

### 3. 科室列表 (card)
- **卡片头部**: 显示"科室列表"标题和记录数统计
- **表格内容**: 使用TableComponents渲染表格
- **空状态**: 显示友好的空数据提示和新增按钮
- **加载状态**: 显示加载动画和提示文字
- **错误状态**: 显示错误信息和重试按钮

## 表格列设计

1. **序号**: 自动编号（1, 2, 3...）
2. **科室名称**: 加粗显示，左对齐
3. **科室编码**: 使用badge样式，居中显示
4. **描述**: 超过50字符自动截断，显示省略号
5. **医生数量**: 使用info badge显示
6. **状态**: 使用success/danger badge显示启用/禁用状态
7. **创建时间**: 格式化显示为YYYY-MM-DD
8. **操作**: 编辑和删除按钮组

## 功能实现

### 1. 列表加载
- 支持分页（默认每页100条）
- 支持搜索过滤
- 显示记录总数
- 加载状态提示
- 错误处理和重试

### 2. 新增科室
- 表单字段：
  - 科室名称（必填）
  - 科室编码（必填，自动转大写）
  - 科室描述（可选）
  - 状态（默认启用）
- 表单验证：
  - 必填字段验证
  - 编码格式验证（只允许大写字母、数字、下划线）
- 提交后自动刷新列表

### 3. 编辑科室
- 加载科室详情
- 科室编码只读（不可修改）
- 可编辑：名称、描述、状态
- 表单验证
- 提交后自动刷新列表

### 4. 删除科室
- 删除前确认提示
- 显示警告信息
- 软删除（设置deleted_at）
- 删除后自动刷新列表

### 5. 搜索功能
- 支持按科室名称或编码搜索
- 支持回车键搜索
- 支持重置搜索条件
- 实时更新列表

## 样式特点

### 1. Bootstrap组件
- `card`: 卡片容器
- `card-header`: 卡片头部
- `card-body`: 卡片内容
- `btn-group`: 按钮组
- `badge`: 标签
- `spinner-border`: 加载动画
- `alert`: 提示信息

### 2. Bootstrap图标 (Bootstrap Icons)
- `bi-building`: 科室图标
- `bi-plus-circle`: 新增图标
- `bi-search`: 搜索图标
- `bi-x-circle`: 重置图标
- `bi-list-ul`: 列表图标
- `bi-pencil`: 编辑图标
- `bi-trash`: 删除图标
- `bi-inbox`: 空状态图标
- `bi-exclamation-triangle`: 警告图标
- `bi-arrow-clockwise`: 重试图标

### 3. 颜色方案
- **主色**: `btn-primary` (蓝色)
- **成功**: `badge-success` (绿色)
- **危险**: `badge-danger` (红色)
- **信息**: `badge-info` (蓝色)
- **次要**: `badge-secondary` (灰色)
- **警告**: `text-warning` (黄色)

### 4. 响应式设计
- 使用Bootstrap网格系统
- 支持移动端和桌面端
- 表格在小屏幕上可横向滚动

## 代码特点

### 1. 全局函数挂载
所有函数都挂载到`window`对象，确保在动态加载的HTML中可访问：
- `window.pageInit()`
- `window.loadDepartments()`
- `window.searchDepartments()`
- `window.resetSearch()`
- `window.showAddDepartmentModal()`
- `window.editDepartment(id)`
- `window.deleteDepartment(id)`

### 2. 错误处理
- 使用`try-catch`捕获错误
- 显示友好的错误提示
- 提供重试功能
- 控制台输出详细错误信息

### 3. 数据格式处理
- 兼容多种响应格式
- 正确处理分页数据
- 格式化日期显示
- 处理空数据状态

### 4. 用户体验优化
- 加载状态提示
- 操作成功提示
- 操作失败提示
- 确认对话框
- 表单验证提示
