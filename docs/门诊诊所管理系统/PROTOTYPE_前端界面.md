# PROTOTYPE_前端界面设计

## 一、设计概述

### 1.1 设计目标
- 界面简洁易用，适合年龄较大的医生使用
- 响应式设计，支持PC、平板、移动端全平台
- 基于Bootstrap 5框架，确保界面美观统一
- 符合医疗行业使用习惯和操作流程

### 1.2 设计原则
- **简洁性**: 界面简洁，避免复杂操作
- **一致性**: 统一的设计语言和交互模式
- **可访问性**: 字体大小适中，对比度良好
- **响应式**: 适配不同屏幕尺寸
- **性能**: 快速加载，流畅交互

### 1.3 技术栈
- **UI框架**: Bootstrap 5.3+
- **图标库**: Bootstrap Icons
- **图表库**: Chart.js (用于报表统计)
- **JavaScript**: ES6+ 原生JavaScript
- **构建工具**: 可选 Webpack/Vite（生产环境优化）

## 二、设计规范

### 2.1 色彩方案

#### 2.1.1 主色调
- **主色（Primary）**: `#0d6efd` (Bootstrap Blue)
- **成功色（Success）**: `#198754` (Bootstrap Green)
- **警告色（Warning）**: `#ffc107` (Bootstrap Yellow)
- **危险色（Danger）**: `#dc3545` (Bootstrap Red)
- **信息色（Info）**: `#0dcaf0` (Bootstrap Cyan)

#### 2.1.2 医疗行业特色色
- **医疗主题色**: `#007bff` (医疗蓝)
- **中医特色色**: `#28a745` (中医绿，用于中医相关功能)
- **西医特色色**: `#17a2b8` (西医蓝，用于西医相关功能)

#### 2.1.3 中性色
- **背景色**: `#f8f9fa` (浅灰背景)
- **文字色**: `#212529` (深灰文字)
- **边框色**: `#dee2e6` (浅灰边框)

### 2.2 字体规范
- **字体族**: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif`
- **标题字体大小**:
  - H1: `2.5rem` (40px)
  - H2: `2rem` (32px)
  - H3: `1.75rem` (28px)
  - H4: `1.5rem` (24px)
  - H5: `1.25rem` (20px)
  - H6: `1rem` (16px)
- **正文字体大小**: `1rem` (16px)
- **小字体**: `0.875rem` (14px)

### 2.3 间距规范
- 使用Bootstrap间距系统（spacing utilities）
- 基础间距单位: `0.25rem` (4px)
- 常用间距: `0.5rem`, `1rem`, `1.5rem`, `2rem`, `3rem`

### 2.4 组件规范

#### 2.4.1 按钮
- 主要操作按钮: `btn btn-primary`
- 次要操作按钮: `btn btn-secondary`
- 危险操作按钮: `btn btn-danger`
- 按钮尺寸: `btn-sm`, `btn-lg` (根据场景选择)

#### 2.4.2 表单
- 表单控件: `form-control`
- 表单标签: `form-label`
- 表单验证: `is-invalid`, `is-valid`
- 表单组: `mb-3` (底部间距)

#### 2.4.3 表格
- 表格样式: `table table-striped table-hover`
- 响应式表格: `table-responsive`
- 表格操作列: 固定在右侧

#### 2.4.4 卡片
- 卡片容器: `card`
- 卡片头部: `card-header`
- 卡片内容: `card-body`
- 卡片底部: `card-footer`

## 七、响应式设计

### 7.1 断点设置（Bootstrap 5）
- xs: < 576px (手机)
- sm: ≥ 576px (手机横屏)
- md: ≥ 768px (平板)
- lg: ≥ 992px (桌面)
- xl: ≥ 1200px (大桌面)
- xxl: ≥ 1400px (超大桌面)

### 7.2 响应式策略
- **移动端**: 侧边栏折叠为汉堡菜单，表格横向滚动
- **平板端**: 侧边栏可折叠，表格正常显示
- **桌面端**: 完整布局，所有功能正常显示

### 7.3 响应式组件
- 表格: `table-responsive`
- 导航: 移动端折叠菜单
- 卡片: 响应式网格布局
