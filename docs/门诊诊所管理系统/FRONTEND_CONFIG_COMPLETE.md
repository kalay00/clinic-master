## 三、前后端集成

### 3.1 API对接

所有API端点已正确对接：
- ✅ `GET /api/v1/third-party/configs` - 获取列表
- ✅ `GET /api/v1/third-party/configs/{service_type}` - 获取配置
- ✅ `POST /api/v1/third-party/configs` - 保存配置
- ✅ `PUT /api/v1/third-party/configs/{service_type}` - 更新配置
- ✅ `DELETE /api/v1/third-party/configs/{service_type}` - 删除配置
- ✅ `POST /api/v1/third-party/configs/{service_type}/test` - 测试配置

### 3.2 错误处理

- ✅ 使用统一的 `ErrorHandler` 组件处理错误
- ✅ API错误自动显示友好提示
- ✅ 网络错误自动重试机制

### 3.3 数据流

1. **加载配置列表**:
   - 前端调用 `ThirdPartyConfigAPI.getList()`
   - 后端返回配置列表（已解密）
   - 前端渲染卡片列表

2. **编辑配置**:
   - 点击"编辑配置"按钮
   - 前端调用 `ThirdPartyConfigAPI.getConfig(serviceType)`
   - 后端返回配置（已解密）
   - 前端填充表单

3. **保存配置**:
   - 前端收集表单数据
   - 调用 `ThirdPartyConfigAPI.saveConfig(data)`
   - 后端加密敏感字段并保存
   - 返回保存结果

4. **测试配置**:
   - 前端收集测试参数
   - 调用 `ThirdPartyConfigAPI.testConfig(serviceType, testParams)`
   - 后端调用第三方服务进行测试
   - 返回测试结果

## 四、使用说明

### 4.1 访问配置页面

1. 登录系统
2. 点击侧边栏"第三方服务配置"或
3. 进入"系统管理" -> "第三方服务配置"

### 4.2 配置服务

1. 在配置列表中找到要配置的服务
2. 点击"添加配置"或"编辑配置"
3. 填写配置参数：
   - 必填字段必须填写
   - 加密字段会加密存储
   - 已加密字段修改时需要重新输入
4. 可选择"测试配置"验证配置是否正确
5. 点击"保存配置"

### 4.3 启用/禁用服务

在配置表单中可以切换"启用此服务"开关

### 4.4 删除配置

点击"删除配置"按钮，确认后删除（不可恢复）
