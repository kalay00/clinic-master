# CONSENSUS_v2.0 - 门诊诊所管理系统 v2.0 版本共识文档

## 一、项目概述

### 1.1 项目名称
门诊诊所管理系统 v2.0（HIS v2.0 - Hospital Information System v2.0）

### 1.2 项目定位
基于v1.0版本的功能增强和体验优化版本，面向中小型门诊、诊所的云端SaaS管理系统，支持多租户、多机构部署，提供完整的门诊业务流程管理，并新增监管合规功能。

### 1.3 目标用户
- 中小型门诊（日接诊量：50-500人次）
- 各类专科诊所（口腔、中医、专科等）
- 中医特色门诊（支持完整的中医诊疗流程）
- 中西医结合门诊（同时支持中医和西医诊疗方式）
- 社区医疗服务站
- 支持多机构、多租户模式

## 三、技术实现方案

### 3.1 技术栈选择

#### 3.1.1 后端技术栈（保持v1.0技术栈，版本升级）
- **开发语言**: Python 3.11+
- **Web框架**: FastAPI（最新稳定版本）
- **ORM框架**: SQLAlchemy（最新版本）
- **异步框架**: FastAPI异步特性 + asyncio
- **任务队列**: Celery + Redis（异步任务处理）
- **API文档**: FastAPI自动生成（Swagger/OpenAPI）

#### 3.1.2 前端技术栈（保持v1.0技术栈，引入构建工具）
- **基础**: 原生 HTML5 + CSS3 + JavaScript (ES6+)
- **UI框架**: Bootstrap 5（保持现有UI框架）
- **构建工具**: Vite（推荐，快速构建）或 Webpack
- **响应式**: CSS Grid/Flexbox实现响应式布局
- **AJAX**: Fetch API进行API调用

#### 3.1.3 数据库（版本升级）
- **主数据库**: PostgreSQL 15+（升级到最新版本）
- **缓存数据库**: Redis 7+（升级到最新版本）

#### 3.1.4 移动端技术栈（新增）
- **微信小程序**: 微信小程序原生开发
- **移动端Web**: 响应式HTML/CSS/JS

#### 3.1.5 监管合规技术栈（新增）

- **数据加密**: AES-256-GCM（保持v1.0加密方式）
