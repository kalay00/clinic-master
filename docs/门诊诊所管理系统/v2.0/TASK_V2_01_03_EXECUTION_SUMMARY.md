## 三、功能实现详情

### 3.1 医保数据采集服务

**实现内容**:
- 从账单数据中采集医保结算数据
- 从患者信息中获取医保相关信息
- 从病历信息中获取诊断和处方信息
- 构建结算明细数据
- 采集违规数据
- 支持批量采集

**关键方法**:
- `collect_settlement_data_from_bill()`: 从账单采集医保结算数据
- `collect_violation_data()`: 采集违规数据
- `collect_batch_settlement_data()`: 批量采集医保结算数据
- `_determine_insurance_type()`: 判断医保类型
- `_calculate_reimbursement_ratio()`: 计算报销比例
- `_build_settlement_details()`: 构建结算明细

**数据采集流程**:
1. 获取账单信息（只采集已支付的账单）
2. 获取患者信息（解密患者数据）
3. 获取病历信息（如果有）
4. 构建医保结算数据
5. 计算报销比例
6. 构建结算明细

### 3.2 医保数据验证服务

**实现内容**:
- 格式验证（必需字段、金额格式、医保卡号格式等）
- 业务规则验证（报销比例、医保支付金额是否符合政策）
- 数据完整性验证（结算明细是否完整）
- 违规数据验证

**关键方法**:
- `validate_settlement_data()`: 验证医保结算数据
- `validate_violation_data()`: 验证违规数据
- `_validate_settlement_format()`: 验证结算数据格式
- `_validate_settlement_business_rules()`: 验证结算数据业务规则
- `_validate_settlement_completeness()`: 验证结算数据完整性
- `_normalize_settlement_data()`: 规范化结算数据

**验证规则**:
1. **格式验证**:
   - 必需字段检查（bill_id、patient_id、total_amount）
   - 金额字段验证（不能为负数、格式正确）
   - 金额一致性验证（总金额 = 医保支付金额 + 个人支付金额）
   - 医保卡号格式验证（长度10-20位）

2. **业务规则验证**:
   - 报销比例是否符合政策限制
   - 医保支付金额是否符合政策限制

3. **完整性验证**:
   - 结算明细是否完整
   - 项目列表是否存在

### 3.3 监管事件处理器

**实现内容**:
- 监听账单支付事件，自动采集医保结算数据
- 监听违规检测事件，自动创建违规记录
- 支持批量结算数据采集
- 记录监管操作日志

**关键方法**:
- `handle_bill_paid_event()`: 处理账单支付事件
- `handle_violation_detected_event()`: 处理违规检测事件
- `handle_batch_settlement_collection()`: 处理批量结算数据采集

**事件处理流程**:
1. **账单支付事件**:
   - 采集医保结算数据
   - 验证数据
   - 创建医保结算记录
   - 记录操作日志

2. **违规检测事件**:
   - 验证违规数据
   - 采集违规数据
   - 创建违规记录
   - 记录操作日志
