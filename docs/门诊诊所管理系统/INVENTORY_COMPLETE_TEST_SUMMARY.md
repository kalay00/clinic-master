3. ✅ 创建采购单（数量：20，单价：45.0）

5. ✅ 验证审核前库存未变化
6. ✅ 审核采购单

### 2.2 完整盘点流程测试

#### 测试步骤

2. ✅ 创建盘点单（实际数量 = 账面数量 + 5）
3. ✅ 验证盘点单详情（账面数量、实际数量、差异数量）
4. ✅ 验证完成盘点前库存未变化
5. ✅ 完成盘点
6. ✅ 验证完成盘点后库存变化（+5）
7. ✅ 验证库存流水记录

#### 验证点
- ✅ 盘点单状态流转：draft → completed
- ✅ 库存调整：账面数量 + 差异数量 = 调整后库存
- ✅ 流水记录：记录类型、差异数量、变动前后库存都正确

### 2.3 数据一致性测试

#### 测试内容
1. ✅ 验证库存流水总和
   - 总入库数量
   - 总出库数量
   - 净变化量
   - 最后一条流水记录的after_quantity等于当前库存

2. ✅ 验证采购单状态流转
   - 采购单状态：received
   - 已入库数量：等于采购数量

3. ✅ 验证盘点单状态流转
   - 盘点单状态：completed

4. ✅ 验证库存流水记录的连续性
   - 每条流水记录的after_quantity等于下一条的before_quantity
