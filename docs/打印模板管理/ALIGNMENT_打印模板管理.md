# 打印模板管理功能 - 对齐文档

## 一、原始需求

### 1.1 需求描述
增加打印模板编辑功能。管理员可以自定义打印模板。在每个打印的界面，可以选择打印模板。打印模板可以自定义命名，支持预览，支持字段拖拽。

### 1.2 需求理解
1. **打印模板管理**：管理员可以创建、编辑、删除打印模板
2. **模板命名**：每个模板可以自定义名称
3. **模板预览**：编辑模板时可以实时预览效果
4. **字段拖拽**：支持通过拖拽方式排列模板字段
5. **模板选择**：在打印界面可以选择使用哪个模板
6. **多场景支持**：需要支持账单、处方、病历等不同打印场景

## 二、项目特性规范

### 2.1 现有项目架构
- **后端**：FastAPI + SQLAlchemy + PostgreSQL
- **前端**：原生 HTML/CSS/JavaScript + Bootstrap 5
- **认证**：JWT Token
- **多租户**：基于 tenant_id 的数据隔离
- **软删除**：使用 deleted_at 字段

### 2.2 现有打印功能
- **账单打印**：`frontend/views/payments/bill-detail.html` - 使用 `window.print()`
- **处方打印**：`frontend/views/treatments/prescription-detail.html` - 使用 `window.print()`
- **病历打印**：`frontend/views/treatments/list.html` - 使用 `window.open()` 打开新窗口

### 2.3 技术约束
- 必须遵循现有代码规范和架构模式
- 使用现有的组件库（FormComponents、ModalComponents等）
- 支持多租户数据隔离
- 使用软删除机制

## 三、需求边界确认

### 3.1 功能范围
✅ **包含的功能**：
- 打印模板的CRUD操作（创建、读取、更新、删除）
- 模板字段定义（字段类型、位置、样式）
- 模板预览功能
- 字段拖拽排序
- 在打印界面选择模板
- 支持多种打印场景（账单、处方、病历等）

❌ **不包含的功能**：

### 3.2 用户角色
- **管理员**：可以创建、编辑、删除打印模板
- **普通用户**：可以在打印时选择模板

## 四、需求理解

### 4.1 打印模板数据结构
```json
{
  "id": "uuid",
  "name": "账单打印模板A",
  "type": "bill",  // bill/prescription/medical_record
  "tenant_id": "uuid",
  "template_config": {
    "header": {
      "title": "门诊收费单",
      "logo": "url",
      "fields": [
        {"name": "bill_no", "label": "账单号", "position": {"x": 0, "y": 0}, "style": {}}
      ]
    },
    "body": {
      "fields": [
        {"name": "patient_name", "label": "患者姓名", "position": {"x": 0, "y": 50}, "style": {}}
      ]
    },
    "footer": {
      "fields": [
        {"name": "total_amount", "label": "总金额", "position": {"x": 0, "y": 100}, "style": {}}
      ]
    }
  },
  "is_default": false,
  "created_at": "datetime",
  "updated_at": "datetime"
}
```

### 4.2 字段类型
- **文本字段**：显示静态文本或动态数据
- **表格字段**：显示列表数据（如账单明细、处方药品）
- **图片字段**：显示Logo等图片
- **分隔线**：用于布局分隔

### 4.3 打印场景
1. **账单打印**（bill）
   - 字段：账单号、患者信息、项目明细、金额、支付信息等
2. **处方打印**（prescription）
   - 字段：处方号、患者信息、药品明细、用法用量、医生签名等
3. **病历打印**（medical_record）
   - 字段：病历号、患者信息、诊断、治疗方案、医生签名等

## 五、疑问澄清

### 5.1 已确认
- ✅ 使用拖拽方式排列字段（类似可视化编辑器）
- ✅ 支持实时预览
- ✅ 模板按类型分类（账单、处方、病历）
- ✅ 每个类型可以有多个模板
- ✅ 可以设置默认模板

### 5.2 待确认
- ❓ 模板字段是否支持条件显示（如：只有已支付才显示支付时间）？
  - **假设**：暂不支持条件显示，后续可扩展
- ❓ 模板是否支持自定义CSS样式？
  - **假设**：支持基本的样式设置（字体、颜色、对齐方式）
- ❓ 字段拖拽是否支持嵌套布局（如：表格内嵌套字段）？
  - **假设**：暂不支持嵌套，使用简单的线性布局
- ❓ 模板预览是否使用真实数据？
  - **假设**：使用模拟数据预览

## 六、技术实现方案

### 6.1 后端实现
1. **数据模型**：`PrintTemplate` 模型
2. **Repository**：`PrintTemplateRepository`
3. **Service**：`PrintTemplateService`
4. **API**：`/api/v1/print-templates` 路由

### 6.2 前端实现
1. **模板管理页面**：`frontend/views/system/print-templates.html`
2. **模板编辑器**：使用拖拽库（如 SortableJS）
3. **模板预览组件**：实时渲染模板
4. **打印界面集成**：在现有打印页面添加模板选择

### 6.3 技术选型
- **拖拽库**：SortableJS（轻量级，兼容性好）
- **模板引擎**：原生JavaScript模板字符串
- **样式**：Bootstrap 5 + 自定义CSS
