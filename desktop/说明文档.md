企业级桌面端应用通用基座模板需求文档（Vue3+Vite+Electron）

## 1. 文档概述

### 1.1 文档目的

本文档定义基于 Vue3 + Vite + Router4 + Axios + SCSS + ECharts + Element Plus + Electron 技术栈构建的**企业级桌面端通用基座模板**完整需求，明确项目架构、功能能力、工程规范、交互标准、适配规则及部署要求。旨在统一企业桌面端Electron应用开发标准，减少重复基建工作，提升项目初始化、开发、迭代、打包部署效率，适用于企业内部管理系统、数据可视化桌面端、业务运营客户端、工具类桌面应用等多场景。

### 1.2 适用范围

适用于公司所有基于Electron开发的Windows/Mac桌面端企业级应用，作为项目初始化基座模板，支撑后续业务功能快速迭代开发，面向前端开发、桌面端开发、测试、运维人员使用。

### 1.3 技术栈定型

本基座采用当前主流稳定企业级技术栈，兼顾性能、开发效率、兼容性和可扩展性，具体技术栈明细如下：

- **核心框架**：Vue3（Composition API + < script setup >）
- **构建工具**：Vite（极速构建、按需编译、热更新）
- **桌面端框架**：Electron（跨平台桌面端打包、原生系统能力调用）
- **路由管理**：Vue Router 4.x
- **网络请求**：Axios（封装统一请求、响应、拦截器）
- **样式方案**：SCSS 全局预编译、样式模块化、主题定制
- **UI组件库**：Element Plus（企业级通用UI）
- **数据可视化**：ECharts（通用图表基座、自适应封装）
- **状态管理**：Pinia（Vue3官方推荐，替代Vuex）
- **代码规范**：ESLint + Prettier 统一代码格式

### 1.4 文档约定

- 基座模板仅提供通用基建能力，不包含具体业务逻辑，保持通用性、纯净性；
- 所有功能设计遵循**企业级稳定性、可维护性、可扩展性**三大原则；
- 兼容Windows 10/11、Mac OS 主流系统版本；
- 支持开发环境热更新、生产环境压缩打包、版本自动更新。

## 2. 项目整体目标

搭建一套**开箱即用、规范统一、性能优异、跨平台**的企业级Electron桌面端基座模板，实现项目初始化零配置、通用能力零重复开发，具备完整的路由、网络、状态、样式、图表、桌面端原生能力、权限、日志、异常处理体系，满足各类企业桌面应用的基础开发需求，大幅降低新项目搭建成本和维护成本。

## 3. 总体架构设计

### 3.1 架构模式

采用 **Electron 主进程 + 渲染进程** 双进程架构，结合Vue3单页应用架构，分离桌面原生能力与前端业务渲染能力：

- **主进程**：负责窗口管理、系统原生调用、文件操作、版本更新、进程通信、权限校验、全局异常监听；
- **渲染进程**：负责页面渲染、业务逻辑、路由跳转、网络请求、图表展示、UI交互、状态管理。

### 3.2 项目目录架构（企业级规范）

目录分层清晰、职责单一，适配大型项目迭代，具体结构如下：

## 4. 核心功能需求

### 4.1 Vite+Vue3 基础基座能力

1. **极速构建与热更新**：基于Vite实现开发环境秒启动、组件热更新，无需全量刷新，提升开发效率；生产环境按需打包、代码压缩、资源预加载。
2. **Vue3 规范开发**：统一使用 setup 语法糖、Composition API，废弃Options API，统一代码书写规范，支持组件抽离、逻辑复用。
3. **全局组件自动注册**：支持Element Plus全局自动引入、自定义公共组件批量自动注册，无需手动引入。
4. **环境变量区分**：支持开发、测试、生产三套环境变量配置，可灵活切换接口地址、打包参数。

### 4.2 Electron 桌面端核心能力

1. **多系统兼容**：支持Windows、Mac双平台打包，适配不同系统窗口样式、状态栏、快捷键。
2. **窗口基础能力**：实现窗口最大化、最小化、关闭、置顶、缩放、居中启动、开机自启。
3. **原生能力封装**：封装文件读写、本地存储、系统弹窗、拖拽、本地日志存储等原生能力。
4. **进程通信封装**：统一封装IPC主进程与渲染进程通信方法，解决跨进程数据传递问题，隔离权限风险。
5. **自动版本更新**：支持检测版本、静默更新、弹窗提示更新、增量更新，无需用户重新下载安装包。
6. **应用签名与打包**：支持生产环境加密打包、安装包压缩、桌面图标配置、版本号统一管理。

### 4.3 Vue Router 4 路由体系

1. **路由模块化**：区分常驻路由（首页、登录、404）和动态业务路由，支持路由懒加载。
2. **全局路由守卫**：封装权限校验、登录状态拦截、页面跳转鉴权、路由白名单配置。
3. **页面权限控制**：支持基于角色的路由权限过滤，动态生成可访问菜单和路由。
4. **路由缓存与重置**：支持页面缓存、路由重置、退出登录清空路由状态，解决路由残留问题。
5. **404/403 异常页面**：内置通用异常页面，拦截无效路由、无权限访问场景。

### 4.4 Axios 网络请求封装

1. **全局请求拦截**：统一添加Token、请求头、时间戳、防重复请求处理。
2. **全局响应拦截**：统一处理成功、失败状态，拦截401、403、500等异常状态码，自动弹窗提示。
3. **接口统一管理**：所有接口按业务模块拆分，统一挂载全局，支持接口路径统一配置。
4. **超时与重试机制**：配置请求超时时间，支持失败请求自动重试、网络异常兜底提示。
5. **请求加载动画**：全局统一loading状态管理，避免重复loading叠加。

### 4.5 SCSS 全局样式体系

1. **全局样式变量**：统一封装主题色、字体、间距、圆角、阴影等通用样式变量，支持一键换主题。
2. **通用混合(mixin)**：封装居中、弹性布局、文字省略、自适应、响应式等通用样式方法。
3. **样式模块化**：区分全局样式、页面样式、组件样式，避免样式污染。
4. **Element Plus 主题定制**：支持覆盖组件默认样式，自定义企业专属主题配色。
5. **适配桌面端分辨率**：适配不同屏幕尺寸，支持窗口缩放样式自适应。

### 4.6 ECharts 数据可视化基座

1. **ECharts 全局封装**：统一初始化、销毁、自适应方法，避免内存泄漏。
2. **通用图表组件**：内置折线图、柱状图、饼图、仪表盘等常用基础图表模板。
3. **窗口自适应**：监听Electron窗口缩放，自动重绘图表。
4. **主题定制**：支持亮色/暗色图表主题切换，适配系统主题。
5. **数据兜底处理**：空数据、异常数据默认展示兜底样式，避免图表报错崩溃。

### 4.7 Element Plus UI 规范体系

1. **按需引入配置**：基于Vite实现Element Plus组件、样式按需引入，减小打包体积。
2. **全局UI规范统一**：统一弹窗、表单、表格、按钮、分页等组件默认样式和交互规则。
3. **通用业务组件封装**：封装通用搜索栏、表格、弹窗、上传组件，减少重复代码。
4. **表单校验统一规范**：封装通用表单校验规则，支持全局复用。

### 4.8 Pinia 状态管理

1. **模块化状态管理**：按用户、权限、全局配置、页面状态拆分Store模块。
2. **持久化存储**：支持关键状态（用户信息、Token、主题配置）本地持久化，刷新不丢失。
3. **状态重置机制**：支持退出登录一键清空所有状态，避免数据残留。

### 4.9 通用基础能力

1. **全局工具类**：封装时间格式化、金额处理、文件导出、参数处理、加密解密等通用方法。
2. **全局异常捕获**：捕获前端代码异常、接口异常、窗口异常，记录本地日志，避免应用崩溃。
3. **日志收集**：支持本地日志存储、日志分级、日志导出，方便问题排查。
4. **主题切换**：支持亮色/暗色主题一键切换，全局样式、图表、UI同步适配。

### 9.2 IPC 跨进程通信（通用封装示例）

统一主进程、预加载脚本、渲染进程通信规范，隔离权限风险，封装同步/异步通信方法，解决桌面端跨进程数据交互核心场景。

#### 9.2.1 预加载脚本暴露全局方法

```javascript
// electron/preload.js
import { contextBridge, ipcRenderer } from 'electron'

// 暴露安全的IPC通信方法至渲染进程
contextBridge.exposeInMainWorld('electronAPI', {
  // 异步通信：渲染进程 -> 主进程
  sendMsg: (channel, data) => ipcRenderer.send(channel, data),
  // 同步通信
  invokeMsg: (channel, data) => ipcRenderer.invoke(channel, data),
  // 监听主进程推送消息
  onMsg: (channel, callback) => ipcRenderer.on(channel, callback)
})
```

#### 9.2.2 主进程监听与响应

```javascript
// electron/main.js
import { ipcMain } from 'electron'

// 监听渲染进程消息
ipcMain.on('window-min', () => {
  mainWindow.minimize()
})

// 同步响应渲染进程
ipcMain.handle('get-app-version', () => {
  return app.getVersion()
})
```

#### 9.2.3 渲染进程调用示例（Vue页面）

```javascript
// .vue 页面内使用
const getVersion = async () => {
  const version = await window.electronAPI.invokeMsg('get-app-version')
```

```javascript
import { dialog } from 'electron'

// 写入本地JSON文件
export const writeLocalFile = (filePath, data) => {
  try {
```

### 9.4 应用自动更新组件（完整示例）

基座内置 Electron 自动更新核心逻辑，支持版本检测、弹窗提示、下载进度监听、静默更新、重启应用，适配企业端版本迭代需求。

```javascript
// electron/update.js 自动更新模块
import { autoUpdater, dialog } from 'electron'

export function initUpdate(win) {
  // 更新服务器地址
  const updateUrl = process.env.VITE_UPDATE_URL
  autoUpdater.setFeedURL({ url: updateUrl })

  // 检测更新
  autoUpdater.checkForUpdates()

  // 发现新版本
  autoUpdater.on('update-available', () => {
    dialog.showMessageBox({
      type: 'info',
      title: '版本更新',
      message: '检测到新版本，正在自动下载更新...'
    })
  })

  // 下载进度
  autoUpdater.on('download-progress', (progress) => {
    win.webContents.send('update-progress', progress.percent)
  })

  // 下载完成
  autoUpdater.on('update-downloaded', () => {
    dialog.showMessageBox({
      type: 'info',
      title: '更新完成',
      message: '新版本已下载完成，重启应用即可更新',
      buttons: ['立即重启', '稍后重启']
    }).then(res => {
      if (res.response === 0) autoUpdater.quitAndInstall()
    })
  })
}
```

- **日志本地存储组件**：封装日志分级（info/warn/error）、本地写入、过期清理、日志导出功能。
- **本地缓存组件**：封装Electron安全本地存储，替代localStorage，支持过期时间配置、加密存储。
- **窗口拖拽组件**：无边框窗口全局拖拽、窗口边界吸附、防超出屏幕。
- **进度条更新组件**：适配应用版本更新下载进度展示、文件导出进度可视化。

### 9.7 开发使用规范

- 所有 Electron 原生能力统一封装在 **electron/utils** 目录，禁止在业务页面直接编写原生代码；
- 严格遵循上下文隔离规范，所有原生API必须通过 preload 脚本暴露，保障应用安全；
- 新增桌面端原生功能，需统一按照现有示例格式封装，保证代码一致性、可复用性；
- 所有示例代码已适配当前技术栈版本，可直接复制复用，无需二次改造。
