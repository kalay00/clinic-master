# 快速开始

## 2.1 环境要求

- Node.js >= 18.0.0
- npm >= 9.0.0 或 yarn >= 1.22.0
- Electron（用于桌面端打包）

## 2.2 安装依赖

```bash
# 克隆项目后进入目录
cd Zzy-VueElectron

# 安装依赖（国内已配置镜像源）
npm install
```

## 2.3 开发模式

### 2.3.1 前端开发（Web 模式）

```bash
# 启动前端开发服务器
npm run dev
```

访问 http://localhost:5173

### 2.3.2 Electron 开发（桌面端模式）

```bash
# 确保 Electron 已正确安装
npx electron --version

# 启动 Electron 开发模式
npm run dev:electron
```

## 2.4 生产构建

### 2.4.1 前端构建

```bash
# 构建生产环境资源
npm run build

# 构建产物输出到 dist 目录
```

### 2.4.2 Electron 打包

```bash
# 构建并打包 Windows 安装包
npm run build:win

# 构建并打包 Mac 安装包
npm run build:mac

# 通用打包命令
npm run build:electron
```

构建产物输出到 `release` 目录。

## 2.5 代码检查

```bash
# 检查代码规范
npm run lint

# 自动修复代码规范问题
npm run lint:fix

# 代码格式化
```

## 2.6 环境配置

项目支持三套环境：

| 环境 | 配置文件 | 用途 |
|------|---------|------|
| development | .env.development | 开发环境 |
| test | .env.test | 测试环境 |
| production | .env.production | 生产环境 |

环境变量示例：

```env
VITE_APP_TITLE=华宣诊所管理系统（开发环境）
VITE_API_BASE_URL=http://localhost:3000/api
VITE_UPDATE_URL=http://localhost:3000/update
```

## 2.8 常见问题

### Q: Electron 下载失败？

国内网络环境建议设置镜像：

```bash
npm config set electron_mirror https://npmmirror.com/mirrors/electron/
npm install electron --save-dev
```

### Q: 依赖安装失败？

```bash
# 清理缓存后重试
npm cache clean --force
rm -rf node_modules
npm install
```

### Q: 端口被占用？

修改 `vite.config.js` 中的端口：

```javascript
server: {
  port: 5174,  // 改为其他端口
}
```
