# 状态管理

## 7.1 Store 模块概览

项目使用 Pinia 进行状态管理，包含以下模块：

| 模块 | 文件 | 说明 |
|------|------|------|
| app | modules/app.js | 应用状态（主题、侧边栏） |
| user | modules/user.js | 用户状态（Token、用户信息） |
| permission | modules/permission.js | 权限状态（路由权限） |
| settings | modules/settings.js | 设置状态 |
| tagsView | modules/tagsView.js | 标签页状态 |
| loading | modules/loading.js | 全局 Loading 状态 |
| operationLog | modules/operationLog.js | 操作日志状态 |

## 7.2 App Store

管理应用全局状态。

### 7.2.1 State

```javascript
{
  sidebarCollapsed: false,    // 侧边栏是否折叠
  isDark: false,              // 是否暗色主题
  themeColor: '#409eff',      // 主题色
  loading: false,             // 全局 loading
  loadingText: '加载中...',    // loading 文本
  device: 'desktop',          // 设备类型
  size: 'default'             // 组件尺寸
}
```

### 7.2.2 使用示例

```javascript
import { useAppStore } from '@/store/modules/app'

const appStore = useAppStore()

// 切换侧边栏
appStore.toggleSidebar()

// 切换主题
appStore.toggleDark()

// 设置主题色
appStore.setThemeColor('#67c23a')

// 显示 loading
appStore.setLoading(true, '数据加载中...')
```

## 7.3 User Store

管理用户登录状态。

### 7.3.1 State

```javascript
{
  token: '',                   // 登录令牌
  userInfo: null,              // 用户信息
  roles: [],                   // 用户角色
  permissions: []              // 用户权限
}
```

### 7.3.2 Getters

```javascript
{
  isLoggedIn: !!state.token,   // 是否已登录
  userName: state.userInfo?.username || '',
  userAvatar: state.userInfo?.avatar || ''
}
```

### 7.3.3 Actions

```javascript
// 登录
await userStore.login({ username, password })

// 获取用户信息
await userStore.getUserInfo()

// 退出登录
await userStore.logout()

// 重置状态
userStore.resetState()
```

### 7.3.4 使用示例

```javascript
import { useUserStore } from '@/store/modules/user'

const userStore = useUserStore()

// 登录
async function handleLogin() {
  await userStore.login({ username: 'admin', password: '123456' })
}

// 获取用户名
const username = userStore.userName

// 检查权限
const canEdit = userStore.permissions.includes('user:edit')
```

## 7.4 Permission Store

管理路由权限。

### 7.4.1 State

```javascript
{
  routes: [],          // 完整路由列表
  addRoutes: [],       // 动态添加的路由
  sidebarRouters: []   // 侧边栏显示的路由
}
```

### 7.4.2 Getters

```javascript
{
  menuRoutes: state.routes.filter(route => !route.meta?.hidden)
}
```

### 7.4.3 Actions

```javascript
// 根据角色生成路由
await permissionStore.generateRoutes(['admin', 'editor'])

// 重置状态
permissionStore.resetState()
```

### 7.4.4 使用示例

```javascript
import { usePermissionStore } from '@/store/modules/permission'

const permissionStore = usePermissionStore()

// 初始化路由
await permissionStore.generateRoutes(['admin'])

// 获取菜单路由
const menuRoutes = permissionStore.menuRoutes
```

## 7.6 TagsView Store

管理标签页状态。

### 7.6.1 State

```javascript
{
  visitedViews: [],  // 访问过的视图
  cachedViews: []    // 缓存的视图（keep-alive）
}
```

### 7.6.2 Actions

```javascript
// 添加标签
tagsViewStore.addView(route)

// 添加缓存
tagsViewStore.addCachedView(route)

// 关闭标签
await tagsViewStore.delView(route)

// 关闭其他标签
await tagsViewStore.delOthersViews(route)

// 关闭所有标签
await tagsViewStore.delAllViews()

// 更新标签
tagsViewStore.updateVisitedView(route)
```

### 7.6.3 使用示例

```javascript
import { useTagsViewStore } from '@/store/modules/tagsView'

const tagsViewStore = useTagsViewStore()

// 关闭当前标签并跳转
async function closeCurrentTag(tag) {
  await tagsViewStore.delView(tag)
  router.push('/dashboard')
}

// 获取已访问标签
const visitedViews = tagsViewStore.visitedViews
```

## 7.8 OperationLog Store

管理操作日志状态。

### 7.8.1 State

```javascript
{
  logs: []  // 操作日志列表
}
```

### 7.8.2 Actions

```javascript
addLog(log)           // 添加日志
clearLogs()           // 清空日志
getLogs()             // 获取所有日志
```

### 7.8.3 日志格式

```javascript
{
  id: '唯一ID',
  timestamp: Date.now(),      // 时间戳
  type: 'info|success|warning|error',  // 日志类型
  message: '操作描述',          // 日志消息
  details: {}                  // 详细信息（可选）
}
```

### 7.8.4 使用示例

```javascript
import { useOperationLogStore } from '@/store/modules/operationLog'

const operationLogStore = useOperationLogStore()

// 记录操作
operationLogStore.addLog({
  type: 'info',
  message: '用户登录',
  details: { username: 'admin' }
})

// 获取日志
const logs = operationLogStore.getLogs()

// 清空日志
operationLogStore.clearLogs()
```

## 7.9 状态持久化

### 7.9.1 配置持久化

使用 pinia-plugin-persistedstate 插件实现状态持久化：

```javascript
// src/store/modules/app.js
export const useAppStore = defineStore('app', {
  state: () => ({
    sidebarCollapsed: false,
    isDark: false
  }),

  persist: {
    key: 'app-store',           // localStorage key
    storage: localStorage,       // 存储方式
    paths: ['sidebarCollapsed', 'isDark']  // 持久化的字段
  }
})
```

### 7.9.2 支持的存储方式

```javascript
// localStorage
persist: {
  storage: localStorage
}

// sessionStorage
persist: {
  storage: sessionStorage
}

// 自定义存储
import { storage } from '@/utils/storage'
persist: {
  storage: {
    getItem: (key) => storage.get(key),
    setItem: (key, value) => storage.set(key, value),
    removeItem: (key) => storage.remove(key)
  }
}
```

## 7.8 状态重置

退出登录时重置所有状态：

```javascript
// src/store/index.js
export function resetAllStore() {
  useUserStore().resetState()
  usePermissionStore().resetState()
  useTagsViewStore().resetState()
  // 不重置 appStore，保留主题等设置
}
```

使用：

```javascript
import { resetAllStore } from '@/store'

async function logout() {
  await userStore.logout()
  resetAllStore()
  router.push('/login')
}
```

## 7.9 Store 最佳实践

1. **模块化拆分**：按功能模块拆分 Store，避免单一 Store 过大
2. **避免在 Store 中处理业务逻辑**：Store 只负责数据存储和简单计算
3. **使用 Getters 代替派生数据**：复杂计算使用 getters
4. **合理使用持久化**：敏感信息不要持久化，定期清理过期数据
5. **状态更新使用 Actions**：保持数据更新的可追踪性
