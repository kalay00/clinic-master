# 路由配置

## 6.1 路由表结构

### 6.1.1 常驻路由

常驻路由是无论登录状态如何都可见的页面，如登录页、404、403 等。

```javascript
// src/router/routes.js

export const constantRoutes = [
  {
    path: '/login',
    name: 'Login',
    component: () => import('@/views/login/index.vue'),
    meta: { title: '登录', hidden: true }
  },
  {
    path: '/redirect/:path(.*)',
    name: 'Redirect',
    component: () => import('@/views/redirect/index.vue'),
    meta: { title: '重定向', hidden: true }
  },
  {
    path: '/404',
    name: '404',
    component: () => import('@/views/error/404.vue'),
    meta: { title: '404', hidden: true }
  },
  {
    path: '/403',
    name: '403',
    component: () => import('@/views/error/403.vue'),
    meta: { title: '403', hidden: true }
  },
  {
    path: '/',
    component: Layout,
    children: [
      {
        path: '',
        name: 'Dashboard',
        component: () => import('@/views/dashboard/index.vue'),
        meta: { title: '首页', icon: 'HomeFilled', affix: true, isFirstMenu: true }
      }
    ]
  },
  {
    path: '/dashboard',
    redirect: '/',
    meta: { hidden: true }
  }
]
```

### 6.1.2 动态路由

动态路由是需要权限校验的页面，根据用户角色动态生成。

```javascript
export const asyncRoutes = [
  {
    path: '/system',
    component: Layout,
    redirect: '/system/user',
    name: 'System',
    meta: {
      title: '系统管理',
      icon: 'Setting',
      roles: ['admin']  // 需要的角色
    },
    children: [
      {
        path: 'user',
        name: 'SystemUser',
        component: () => import('@/views/system/user.vue'),
        meta: {
          title: '用户管理',
          icon: 'User',
          roles: ['admin']
        }
      }
    ]
  }
]
```

## 6.2 路由元信息 (meta)

| 属性 | 类型 | 说明 |
|------|------|------|
| title | string | 页面标题 |
| icon | string | 菜单图标 |
| hidden | boolean | 是否在菜单中隐藏 |
| affix | boolean | 是否固定在标签页 |
| noCache | boolean | 是否缓存（默认缓存） |
| roles | array | 允许访问的角色 |
| sidebar | boolean | 是否显示侧边栏 |
| isFirstMenu | boolean | 是否作为一级菜单显示（首页专用） |
| alwaysShow | boolean | 是否强制显示为父级菜单（即使只有一个子路由） |

## 6.3 路由守卫

### 6.3.1 权限校验流程

```javascript
// src/router/guard.js

router.beforeEach(async (to, from, next) => {
  // 1. 设置页面标题
  document.title = to.meta?.title ? `${to.meta.title} - ${config.title}` : config.title

  // 2. 检查是否已登录
  const hasToken = userStore.token

  if (hasToken) {
    if (to.path === '/login') {
      // 已登录访问登录页，跳转到首页
      next({ path: '/' })
    } else {
      // 检查是否有用户信息
      if (userStore.roles.length === 0) {
        try {
          // 获取用户信息
          await userStore.getUserInfo()
          // 生成动态路由
          const accessRoutes = await permissionStore.generateRoutes(userStore.roles)
          // 添加动态路由
          accessRoutes.forEach(route => router.addRoute(route))
          next({ ...to, replace: true })
        } catch (error) {
          // 获取信息失败，清除状态并跳转登录
          userStore.resetState()
          next(`/login?redirect=${to.path}`)
        }
      } else {
        next()
      }
    }
  } else {
    // 未登录，检查是否在白名单
    if (whiteList.includes(to.path)) {
      next()
    } else {
      // 跳转登录页
      next(`/login?redirect=${to.path}`)
    }
  }
})
```

## 6.4 路由定义规范

### 6.4.1 命名规范

- **路由名称**：PascalCase（首字母大写驼峰）
- **路由路径**：kebab-case（短横线分隔）
- **组件名称**：PascalCase

```javascript
{
  path: 'user-management',      // kebab-case
  name: 'UserManagement',       // PascalCase
  component: UserManagement,    // PascalCase
  meta: {
    title: '用户管理'           // 中文描述
  }
}
```

### 6.4.2 嵌套路由

```javascript
{
  path: '/system',
  component: Layout,
  children: [
    {
      path: 'user',           // 相对路径
      // 完整路径为 /system/user
    }
  ]
}
```

### 6.4.3 重定向

```javascript
{
  path: '/',
  redirect: '/dashboard'  // 重定向到首页
}

{
  path: '/:pathMatch(.*)*',
  redirect: '/404'       // 捕获所有未匹配路由
}
```

## 6.5 权限控制

### 6.5.1 页面级权限

通过路由 meta.roles 控制：

```javascript
{
  path: '/admin',
  component: Admin,
  meta: {
    roles: ['admin']  // 只有 admin 角色可访问
  }
}
```

### 6.5.2 按钮级权限

```vue
<template>
  <!-- 使用 v-if 控制按钮权限 -->
  <el-button v-if="hasPermission('user:create')" type="primary">
    新增
  </el-button>

  <!-- 或使用自定义指令 -->
  <el-button v-permission="['admin', 'editor']" type="success">
    编辑
  </el-button>
</template>

<script setup>
import { useUserStore } from '@/store/modules/user'

const userStore = useUserStore()

function hasPermission(permission) {
  return userStore.permissions.includes(permission)
}
</script>
```

## 6.6 标签页管理

### 6.6.1 标签页状态

```javascript
import { useTagsViewStore } from '@/store/modules/tagsView'

const tagsViewStore = useTagsViewStore()

// 访问的视图会自动添加到标签页
// 可通过 store 手动操作
tagsViewStore.addView(route)    // 添加标签
tagsViewStore.delView(route)    // 关闭标签
tagsViewStore.delOthersViews()  // 关闭其他标签
tagsViewStore.delAllViews()     // 关闭所有标签
```

### 6.6.2 标签页持久化

标签页状态默认存储在内存中，如需持久化可在 store 中配置。

## 6.7 路由重置

退出登录时需要重置路由状态：

```javascript
import { resetRouter } from '@/router'
import { resetAllStore } from '@/store'

async function logout() {
  resetRouter()          // 重置路由
  resetAllStore()        // 重置所有状态
  router.push('/login')
}
```

## 6.8 路由懒加载

所有页面组件都使用懒加载，优化首屏加载速度：

```javascript
// 同步导入（不推荐，会影响首屏速度）
import Dashboard from '@/views/dashboard/index.vue'

// 懒加载（推荐）
const Dashboard = () => import('@/views/dashboard/index.vue')

// 路由中配置
{
  path: '/dashboard',
  component: () => import('@/views/dashboard/index.vue')
}
```
