# 项目介绍

## 1.1 项目概述

企业级桌面端应用通用基座模板（Vue3 + Vite + Electron）是一套开箱即用、规范统一、性能优异的企业级桌面端应用开发基座。旨在统一企业桌面端 Electron 应用开发标准，减少重复基建工作，提升项目初始化、开发、迭代、打包部署效率。

## 1.3 核心特性

### 1.3.1 双进程架构

采用 Electron 主进程 + 渲染进程双进程架构：

- **主进程**：窗口管理、系统原生调用、文件操作、版本更新、进程通信、权限校验、全局异常监听
- **渲染进程**：页面渲染、业务逻辑、路由跳转、网络请求、图表展示、UI交互、状态管理

### 1.3.2 极速开发体验

- Vite 极速启动（~1.9s）
- 组件热更新，无需全量刷新
- 生产环境按需打包、代码压缩
- 代码分割，资源预加载

### 1.3.3 企业级功能

- 完整权限管理体系（路由权限、按钮权限）
- 统一网络请求封装（拦截、重试、错误处理）
- 状态持久化（刷新不丢失）
- 主题切换（亮色/暗色）
- 日志收集与导出
- 自动版本更新

### 1.3.4 数据可视化

- ECharts 全局封装
- 通用图表组件（折线图、柱状图、饼图、仪表盘）
- 窗口自适应重绘
- 数据兜底处理

## 1.4 适用场景

- 企业内部管理系统
- 数据可视化桌面端
- 业务运营客户端
- 工具类桌面应用

## 1.7 版本说明

项目使用语义化版本号（Semantic Versioning）：

```
主版本.次版本.修订版本
例如：1.0.0
```

- **主版本**：不兼容的 API 修改
- **次版本**：向后兼容的功能性新增
- **修订版本**：向后兼容的问题修正
