## 8.2 混合 (Mixin)

### 8.2.1 弹性盒模型

```scss
// 居中
@include flex-center;

// 两端对齐
@include flex-between;

// 列方向
@include flex-column;

// 列方向居中
@include flex-column-center;
```

### 8.2.2 文本省略

```scss
// 单行省略
@include ellipsis;

// 多行省略（传入行数）
@include ellipsis(2);
```

### 8.2.3 滚动条

```scss
// 自定义滚动条
@include scrollbar;
```

### 8.2.4 绝对定位

```scss
// 居中定位
@include absolute-center;

// 填充定位
@include absolute-fill;

// 固定填充
@include fixed-fill;
```

### 8.2.5 其他

```scss
// 清除浮动
@include clearfix;

// 卡片阴影
@include card-shadow;

// 悬停效果
@include hover-effect;

// 响应式
@include responsive(sm) {
  // 小屏幕样式
}
```

## 8.3 全局样式类

### 8.3.1 布局类

```html
<div class="flex-1">占据剩余空间</div>
```

### 8.3.2 文本类

```html
<span class="text-center">居中文本</span>
<span class="text-left">左对齐</span>
<span class="text-right">右对齐</span>
```

### 8.3.3 间距类

```html
<div class="mt-base">上边距</div>
<div class="mb-base">下边距</div>
<div class="ml-base">左边距</div>
<div class="mr-base">右边距</div>
<div class="p-base">内边距</div>
```

间距级别：xs (4px)、sm (8px)、md (12px)、base (16px)、lg (20px)、xl (24px)

## 8.4 组件样式规范

### 8.4.1 作用域样式

```vue
<style lang="scss" scoped>
.card {
  padding: 16px;
  background: #fff;
}
</style>
```

### 8.4.2 深度选择器

```vue
<style lang="scss" scoped>
.card {
  :deep(.el-button) {
    margin-right: 8px;
  }

  :global(.external-class) {
    color: red;
  }
}
</style>
```

## 8.5 响应式断点

| 断点 | 宽度 | 说明 |
|------|------|------|
| xs | <= 768px | 超小屏幕 |
| sm | <= 992px | 小屏幕 |
| md | <= 1200px | 中等屏幕 |
| lg | <= 1920px | 大屏幕 |

```scss
// 使用混合
@include responsive(sm) {
  .container {
    flex-direction: column;
  }
}

// 使用媒体查询
@media (max-width: 768px) {
  .sidebar {
    display: none;
  }
}
```

## 8.7 Element Plus 定制

### 8.7.1 主题覆盖

在 `src/assets/scss/element-plus.scss` 中定制：

```scss
// 主按钮颜色
.el-button--primary {
  --el-button-bg-color: $primary-color;
  --el-button-border-color: $primary-color;
}

// 表格样式
.el-table {
  --el-table-header-bg-color: $bg-color;
}
```

### 8.7.2 CSS 变量

```scss
// 使用 Element Plus CSS 变量
.card {
  color: var(--el-text-color-primary);
  background: var(--el-bg-color);
  border: var(--el-border-color);
}
```


## 8.9 最佳实践

1. **优先使用变量**：避免硬编码颜色、间距等值
2. **使用混合简化重复代码**：常用样式封装为 mixin
3. **保持样式模块化**：页面样式、组件样式、全局样式分开
4. **合理使用 scoped**：防止样式污染全局
5. **避免过于具体的选择器**：优先使用类选择器
6. **保持命名一致**：统一命名规范
