# 常见问题

## 10.1 安装问题

### Q: npm install 失败？

**A:** 尝试以下解决方案：

```bash
# 1. 清理缓存
npm cache clean --force

# 2. 删除 node_modules
rm -rf node_modules package-lock.json

# 3. 使用淘宝镜像
npm config set registry https://registry.npmmirror.com

# 4. 重新安装
npm install
```

### Q: Electron 下载失败？

**A:** 设置 Electron 镜像：

```bash
# 方式一：命令行设置
npm config set electron_mirror https://npmmirror.com/mirrors/electron/

# 方式二：环境变量
set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/

# 方式三：.npmrc 文件（项目已配置）
electron_mirror=https://npmmirror.com/mirrors/electron/
```

### Q: node-sass 安装失败？

**A:** 使用 sass 替代：

```bash
# 卸载 node-sass
npm uninstall node-sass

# 安装 sass（Dart Sass）
npm install sass --save-dev
```

## 10.2 开发问题

### Q: Vite 启动失败，端口被占用？

**A:** 修改 vite.config.js 中的端口：

```javascript
server: {
  port: 5174  // 改为其他端口
}
```

或使用命令行指定：

```bash
npm run dev -- --port 5174
```

### Q: 热更新不生效？

**A:** 检查以下几点：

1. 确保使用的是 `npm run dev` 而不是 `node vite`
2. 检查浏览器控制台是否有报错
3. 尝试清除浏览器缓存
4. 重启开发服务器

### Q: ESLint 报错过多？

**A:** 临时禁用或修复：

```bash
# 自动修复
npm run lint:fix

# 禁用 ESLint（不推荐）
// 在 .eslintrc.js 中
rules: {
  'no-console': 'off',
  'no-debugger': 'off'
}
```

## 10.3 构建问题

### Q: 构建后样式异常？

**A:** 检查 SCSS 引入：

```javascript
// vite.config.js
css: {
  preprocessorOptions: {
    scss: {
      additionalData: `
        @use "@/assets/scss/variables.scss" as *;
        @use "@/assets/scss/mixin.scss" as *;
      `
    }
  }
}
```

### Q: 生产环境白屏？

**A:** 可能原因及解决方案：

1. **资源路径问题**：检查 base 配置
2. **路由模式**：Electron 建议使用 hash 模式
3. **跨域问题**：检查代理配置

### Q: 打包后体积过大？

**A:** 优化措施：

1. 检查代码分割配置
2. 移除未使用的依赖
3. 压缩图片资源
4. 启用 gzip 压缩

## 10.4 Electron 问题

### Q: Electron 窗口不显示？

**A:** 检查主进程日志：

```javascript
// 在主进程入口添加日志
console.log('主进程启动')
console.log('加载URL:', url)
```

### Q: IPC 通信失败？

**A:** 检查以下几点：

1. 预加载脚本是否正确加载
2. channel 名称是否匹配
3. 异步/同步调用是否正确使用

### Q: 打包后无法运行？

**A:** 常见原因：

1. **路径问题**：使用 `__dirname` 和 `path.join`
2. **权限问题**：检查文件访问权限
3. **缺少依赖**：确保所有依赖都打包

### Q: 自动更新不生效？

**A:** 检查：

1. 更新服务器是否可用
2. 版本号是否正确
3. 是否在非开发环境

## 10.5 样式问题

### Q: 样式不生效？

**A:** 检查优先级和作用域：

```vue
<!-- 检查是否使用 scoped -->
<style scoped>
.card { ... }
</style>

<!-- 深度选择器 -->
<style scoped>
:deep(.el-table) { ... }
</style>
```

### Q: 暗色主题不生效？

**A:** 确保正确切换主题：

```javascript
appStore.toggleDark()  // 切换主题
```

## 10.6 路由问题

### Q: 路由跳转后页面空白？

**A:** 检查：

1. 组件是否正确导入
2. 路由路径是否正确
3. 动态路由是否正确添加

### Q: 权限路由不生效？

**A:** 检查：

1. 用户角色是否正确设置
2. 路由 meta.roles 配置
3. generateRoutes 是否正确调用

### Q: 退出登录后路由未重置？

**A:** 确保调用重置方法：

```javascript
import { resetRouter } from '@/router'
import { resetAllStore } from '@/store'

logout() {
  resetRouter()
  resetAllStore()
  router.push('/login')
}
```

## 10.7 状态管理问题

### Q: 状态不持久化？

**A:** 检查 persist 配置：

```javascript
persist: {
  key: 'app-store',
  storage: localStorage,
  paths: ['sidebarCollapsed']  // 指定要持久化的字段
}
```

### Q: 刷新后状态丢失？

**A:** 确保使用正确的持久化配置，并检查 localStorage 是否正常工作。

## 10.8 其他问题

### Q: 如何查看版本信息？

**A:** 在控制台或代码中：

```javascript
// 渲染进程
console.log(__APP_VERSION__)

// Electron 主进程
app.getVersion()
```

### Q: 如何调试 Electron？

**A:** 打开开发者工具：

```bash
# 渲染进程：在应用中按 F12
# 主进程：在启动时添加调试参数
electron . --remote-debugging-port=9222
```

### Q: 如何查看日志？

**A:** 日志文件位置：

```javascript
// Electron 日志
const { app } = require('electron')
console.log(app.getPath('userData'))  // 日志目录
```
