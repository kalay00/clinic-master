# 目录规范

## 3.1 总体目录结构

```
electron-vue3-base/
├── electron/                  # Electron 主进程
│   ├── main.js               # 主进程入口
│   ├── preload.js            # 预加载脚本
│   ├── update.js             # 版本更新模块
│   ├── package.json          # 主进程模块配置
│   └── utils/                # 主进程工具
│       ├── file.js           # 文件操作工具
│       └── logger.js         # 日志工具
├── src/                      # 渲染进程（前端）
│   ├── api/                  # 接口请求
│   ├── assets/               # 静态资源
│   │   └── scss/            # SCSS 样式
│   ├── components/           # 公共组件
│   ├── config/               # 全局配置
│   ├── echarts/              # ECharts 封装
│   ├── layout/               # 布局组件
│   │   └── components/      # 布局子组件
│   ├── router/               # 路由配置
│   ├── store/                # 状态管理
│   │   └── modules/         # Store 模块
│   ├── utils/                # 工具函数
│   ├── views/                # 页面视图
│   │   ├── dashboard/       # 首页
│   │   ├── error/          # 异常页面
│   │   ├── login/          # 登录页
│   │   ├── settings/       # 设置页
│   │   └── system/         # 系统管理
│   ├── App.vue              # 根组件
│   └── main.js              # 渲染进程入口
├── public/                   # 公共资源
├── DOC/                      # 项目文档
├── package.json
├── vite.config.js
├── .env.development
├── .env.test
├── .env.production
├── .eslintrc.js
├── .prettierrc
└── .gitignore
```

## 3.2 目录职责说明

### 3.2.1 electron/ 目录

| 文件/目录 | 说明 |
|----------|------|
| main.js | 主进程入口，负责窗口创建、IPC 监听、系统菜单 |
| preload.js | 预加载脚本，安全暴露 API 给渲染进程 |
| update.js | 自动更新模块，处理版本检测和下载更新 |
| utils/file.js | 文件读写、对话框等文件操作 |
| utils/logger.js | 日志记录、导出、清理 |

### 3.2.2 src/api/ 目录

接口模块化，按业务拆分为独立文件：

```
api/
├── index.js        # 统一导出
├── user.js         # 用户相关接口
├── system.js       # 系统管理接口
└── dashboard.js     # 仪表盘接口
```

### 3.2.3 src/assets/scss/ 目录

| 文件 | 说明 |
|------|------|
| variables.scss | 全局 SCSS 变量（颜色、字体、间距等） |
| mixin.scss | 全局混合（flex、ellipsis、scrollbar 等） |
| index.scss | 全局样式重置、通用类 |
| element-plus.scss | Element Plus 主题定制 |

### 3.2.4 src/components/ 目录

全局公共组件，自动注册到项目。

### 3.2.5 src/echarts/ 目录

| 文件 | 说明 |
|------|------|
| BaseChart.vue | 基础图表组件 |
| useChart.js | Chart Composable |
| chartOptions.js | 图表配置工厂函数 |
| index.js | 统一导出 |

### 3.2.6 src/layout/ 目录

| 文件 | 说明 |
|------|------|
| index.vue | 主布局组件 |
| components/Sidebar.vue | 侧边栏组件 |
| components/Navbar.vue | 顶部导航栏 |
| components/TagsView.vue | 标签页组件 |
| components/TitleBar.vue | 自定义标题栏（Electron） |
| components/AppFooter.vue | 页脚组件 |

### 3.2.7 src/router/ 目录

| 文件 | 说明 |
|------|------|
| index.js | 路由实例创建、导出 |
| routes.js | 路由表配置（常驻路由 + 动态路由） |
| guard.js | 路由守卫（权限校验、登录拦截） |

### 3.2.8 src/store/ 目录

| 文件 | 说明 |
|------|------|
| index.js | Store 导出、状态重置 |
| modules/app.js | 应用状态（侧边栏、主题） |

| modules/permission.js | 权限状态（路由权限） |
| modules/settings.js | 设置状态 |
| modules/tagsView.js | 标签页状态 |

### 3.2.9 src/utils/ 目录

| 文件 | 说明 |
|------|------|
| index.js | 通用工具函数（日期、金额、防抖等） |
| request.js | Axios 请求封装 |
| storage.js | 本地存储封装 |
| message.js | 消息提示封装 |
| validate.js | 表单校验规则 |
| errorHandler.js | 全局异常捕获 |
| logger.js | 日志工具 |
| globalProperties.js | Vue 全局属性配置 |

### 3.2.10 src/views/ 目录

按功能模块划分页面：

```
views/
├── dashboard/     # 首页仪表盘
├── error/         # 异常页面（404、403）
├── login/         # 登录页
├── settings/      # 设置页面
│   ├── basic.vue  # 基础设置
│   └── about.vue  # 关于页面
├── system/        # 系统管理
│   ├── user.vue   # 用户管理
│   ├── role.vue   # 角色管理
│   └── menu.vue   # 菜单管理
└── chart/         # 图表示例
```

## 3.3 命名规范

### 3.3.1 文件命名

- 组件文件：PascalCase（大驼峰）
  - 例：`UserList.vue`、`BaseChart.vue`
- 工具文件：camelCase（小驼峰）
  - 例：`request.js`、`storage.js`
- 样式文件：kebab-case（短横线）
  - 例：`variables.scss`、`element-plus.scss`

### 3.3.2 目录命名

统一使用 kebab-case：

```
src/
├── components/
├── layout/
├── router/
└── store/
```

### 3.3.3 CSS 类名

使用 BEM 命名规范：

```scss
.block {}
.block__element {}
.block--modifier {}
```

或使用 kebab-case：

```scss
.sidebar-container {}
.sidebar-title {}
.sidebar-container--collapsed {}
```
